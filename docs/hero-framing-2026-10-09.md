# 顶部幻灯片铺满布局验收 · 2026-10-09

本次将轮播视觉层扩展到整个 hero，覆盖顶部、左右边缘和文案后方。桌面清晰图可以从动物展示区域向左延伸；完整动物仍在文案右侧，按照已审核的轮廓边界保留至少 24px 间距。清晰图未覆盖的部分使用同一张封面的模糊背景，文案和页脚后方叠加深色渐变。

手机保留图片在前、文案和控制按钮在后的布局，模糊背景覆盖整个 hero。清晰图继续在图片区域的 24px 内边距中完整显示。轮播继续使用无缩放、无位移的交叉淡入，元数据加载期间继续使用完整图片 contain 回退。

## 几何与交互验证

- `npm run test:carousel` 通过：检查全部 530 个物种的六张图片、封面哈希、实际解码尺寸、审核轮廓与最大适配尺度。
- 几何检查覆盖 `320×760`、`390×760`、`761×760`、`900×760`、`1100×768`、`1366×768`、`1920×900`、`2560×900`、`3840×900`。桌面额外检查文案使 hero 增高 160px 的情况。
- CSS 回归检查约束整幅视觉层、桌面图片向面板外延伸、手机图片区域与文案分行。初始、前进及后退的进入和离开动画都只改变透明度，因此端点沿用同一套轮廓几何。
- JSDOM 交互检查通过，包括前后切换、自动播放、减少动态效果、图片解码失败、已绘制节点保留、尺寸更新、观察器清理与无元数据回退。
- `npm run test:dist-subpath` 通过，包括生产构建、子路径图片访问和 JavaScript 体积限制。`git diff --check` 通过。

## 图片检查与限制

本次保留封面文件和轮廓元数据，沿用既有源图审核记录。另检查大熊猫、丹顶鹤、漂泊信天翁和网纹蟒的保留 WebP，按本次 CSS 几何生成九种视口下的 36 张静态图片模拟，检查高瘦轮廓、展翅和长身体的边缘间距。模拟图包含清晰前景、同图模糊背景和渐变遮罩，不包含浏览器排版。

静态几何和图片模拟不能验证浏览器字体、文案实际高度或完整页面效果。本次按照仓库要求没有启动浏览器。
