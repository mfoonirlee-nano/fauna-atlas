# 下一批五种：狮鬃海蛞蝓与海绵背蟹研究

日期：2026-10-23。本文支撑两个新物种档案的文字和画面设计。已写入 `src/data/species/lion-mane-nudibranch.ts` 与 `src/data/species/sponge-crab.ts`；图像生成、封面验收、目录接入和整体测试由主任务完成。本文不把文字档案完成视为图片已通过验收。

## 狮鬃海蛞蝓 Melibe leonina

[WoRMS 接受种记录](https://www.marinespecies.org/aphia.php?id=575441&p=taxdetails)链接 Gould 在 1852 年的原始描述，原组合为 *Chioraera leonina*，模式产地记录与 Puget Sound 有关。*Chioraera dalli*、*Melibe pellucida* 等旧名不能额外计数。[OBIS 路径](https://obis.org/taxon/575441)为 Animalia / Mollusca / Gastropoda / Nudibranchia / Tethydidae / Melibe。科中文名“大嘴海牛科”取[中央研究院贝类资料库](https://shell.sinica.edu.tw/english/shellfamily.php?ORDER=family&PAGE=1&pageNum_Recordset1=18&totalRows_Recordset1=293)，属译“大嘴海蛞蝓属”作编辑用译名。

[UCSC Gary McDonald 的原始观察照片](https://people.ucsc.edu/~mcduck/DreamWeaver/Mollusca/Nudibranchs/Melibe_leonina/Melibe_leonina.html)显示半透明淡黄褐色身体、椭圆形口兜及宽扁背突，还提供捕食序列和游泳照片。[Walla Walla 大学观察](https://inverts.wallawalla.edu/Mollusca/Gastropoda/Opisthobranchia/Nudibranchia/Dendronotacea/Melibe_leonina.html)记录四至六对背突沿背部两列排列、口兜边缘两列细触须，以及嗅角的耳状与帆状细节。旧网页个别命名年份、科名拼写与当前口径不同，分类采用 WoRMS / OBIS。

[蒙特雷湾水族馆](https://www.montereybayaquarium.org/animals-the-ocean/animals-a-to-z/melibe)记录其在海带叶片上扫动口兜捕食桡足类等动物，收拢口兜游泳，以及长胶质卵带。该馆给出的范围为阿拉斯加至加利福尼亚湾。档案不使用不一致的最大体长数字，也没有把气味的可能功能写成定论。[1983 年原始发育研究](https://doi.org/10.2307/1541359)直接观察幼体与变态，说明成体的裸露外形不能推导为整个发育过程都没有壳。

## 海绵背蟹 Dromia personata

[WoRMS](https://www.marinespecies.org/aphia.php?id=107258&p=taxdetails)记录林奈于 1758 年以 *Cancer personata* 描述本种，链接《自然系统》第十版第 628 页。[OBIS](https://obis.org/taxon/107258)给出 Animalia / Arthropoda / Malacostraca / Decapoda / Dromiidae / Dromia。科名“绵蟹科”和属译名与现有中文甲壳动物文献用法一致，例如[国立台湾博物馆绵蟹科研究](https://decapoda.nhm.org/pdfs/20399/20399.pdf)；该参考只支持科属中文名，不作为本种在台湾分布证据。

[MarLIN 的本种说明与原图](https://www.marlin.ac.uk/species/detail/1232)记录圆拱甲壳、细密褐色短毛、粉白螯尖，第四第五对胸足短小、朝背侧、末端呈不完整钳状。[格拉纳达大学原始水下图册](https://litoraldegranada.ugr.es/el-litoral/el-litoral-sumergido/fauna/artropodos/crustaceos/decapodos/braquiuros/dromia-personata/)包含后两对足与螯足细节及岩缝栖息照片，供图像逐部位参考。五对胸足包括一对螯足、两对步行足、两对向上抓握的短后足；不能画成八条完整长步足外加螯足，再额外增加抓握足。

[Bedini 等 2003 年原始实验](https://www.vliz.be/imisdocs/publications/289289.pdf)在水族箱中向多个蟹种提供不同伪装材料，包含 *D. personata*。档案只讲可观察的材料选择，不把实验比例外推为野外固定偏好。[2017 年荷兰记录原始论文](https://www.vliz.be/imisdocs/publications/312811.pdf)支持北海及地中海、东大西洋分布信息。地图只用地中海西部代表点，不将单点当完整范围。

饮食使用[意大利地中海水族协会的本种饲养记录](https://www.aiamitalia.it/index.php?Itemid=84&genere=Dromia&option=com_schede&specie=personata&view=scheda)：观察到藻类、小型海底动物及碎屑，录为杂食，不承诺野外食物比例。这是饲养观察而非全球野外食性定量研究。背上抓握海绵属于携带覆盖物，不能据此直接写成海绵是它的主食。

| 文件 | 场景与检查重点 |
| --- | --- |
| 01-cover | 右侧完整个体背海绵走过岩底，粉白螯尖可见，海绵不遮没整个蟹形，左侧安静水体 |
| 02-observation | 侧前方完整行走姿态，短后足固定海绵，前两对步行足着地 |
| 03-observation | 低侧后角度，露出两对短后足抓住海绵下缘；允许真实遮挡，不画透明海绵或穿模足 |
| 04-observation | 无覆盖物个体正面体貌，观察粗壮等大螯、粉白指端及短毛；无需展露所有十条足 |
| 05-observation | 背海绵个体停在岩缝旁，覆盖物与岩石保持可辨的边界 |
| 06-observation | 侧后细节表现海绵与甲壳是两套组织，后足在其间抓握；海绵颜色只示一种情景 |
