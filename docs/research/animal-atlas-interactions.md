## 页面行为

原树形图谱、地理分布和单屏总览通过常驻入口切换，生产环境均可用。新视图按需加载。

地理分布使用本地 Natural Earth 陆地底图与 Equal Earth 投影，不包含国界。只使用现有档案的代表坐标，不从地区名称推断坐标，也不把点位画作完整分布范围。地图支持拖动、点位选择、搜索结果定位和打开物种档案。没有坐标的档案仍出现在列表里。

2026-10-16 调整地理分布交互：点击地图获得焦点后可滚轮连续缩放，未聚焦时保留页面滚动；Ctrl / Command + 滚轮也可缩放。滚轮与双击围绕指针位置缩放，触屏支持双指缩放与双指转单指拖动。拖动在稳定的 SVG 上捕获指针，取消或丢失捕获时结束手势，拖动后的点击不选择点位。地图移动边界随缩放倍率约束；底图与标记通过同一视图状态逐帧更新，减少连续手势与独立 CSS 动画的冲突，并遵守减少动态效果设置。

点位大小按实际屏幕尺寸保持，聚合只在固定倍率档位重算。点击聚合点后，在侧栏以两列封面与名称展示该点位的全部候选物种，用户再选择档案。封面复用目录中的同一张 WebP，完整包含图片并按需加载；缺图或加载失败时保留占位和物种名称。小屏幕将点位图文列表放在地图下方；缩放与地区定位保留当前候选列表和物种选择，点击空白处可清除选择，恢复全球会重置选择。选中物种时只在侧栏内部调整滚动，不滚动整个页面。

单屏总览沿用共用分类树，保留缺纲、缺目的省略规则。在每个阶元只绘制当前分类单元的直接子节点，以免同时绘制六百余个物种导致文字与操作目标过小。侧栏列出当前节点，包括面积较小的色块。面积只表示本图册收录的物种数量，不表示自然界多样性估计或亲缘远近。

搜索覆盖中文名、英文名、别名、学名、分类名称、地区、栖息地与标签。搜索或生态环境筛选变化后清除旧的点位选择和分类路径。地理分布保留当前视角，零结果也保留地图，用户可以点击“定位全部结果”调整视角；单屏总览回到该结果集的总览。

地图与分类总览在桌面采用图与侧栏布局，小屏幕采用上下布局。探索工作区使用动态视口高度，侧栏内部滚动，分类逐层替换，不随分类数量增加页面高度。

地图工具栏与底部说明占用各自的布局空间，避免遮挡点位。窄屏幕以纵向列表展示候选与档案；长列表跳过屏幕外内容的布局和绘制。标记使用共享的缩放变量保持屏幕尺寸，React 缓存标记子树与列表，平移和同一聚合档位内的缩放不再重建它们。移除底图与各标记的滤镜阴影，并只在手势期间提示变换优化。

“展开所选点位”按候选代表坐标调整视角并保留列表；同坐标候选在最高倍率下仍可从列表选择。键盘聚焦屏幕外标记时将其移入视野，标记聚焦后也支持方向键和倍率快捷键，Home 恢复全球。系统取消触摸或丢失捕获后抑制残留点击。

## Canvas 地图重写

日期：2026-10-23。用户要求参考社区实践，用 Canvas 重做地理分布。原实现使用 SVG 地理路径与多层标记元素，缩放动画通过 React 逐帧更新。相邻网格的聚合中心还可能贴在一起，形成重叠圆点。

### 参考与采用方式

| 一手参考 | 本项目采用的做法 |
| --- | --- |
| [D3 / Mike Bostock：Zoom (Canvas)](https://observablehq.com/@d3/zoom-canvas) | 相机变换与 Canvas 绘制分离，手势改变视角后重绘，保持底图和点位使用同一帧的坐标。 |
| [D3：Geographic paths](https://d3js.org/d3-geo/path) | 继续使用 Equal Earth 投影，把本地 Natural Earth 陆地、球面和经纬网编译为缓存的 Path2D。 |
| [MDN：Optimizing canvas](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Optimizing_canvas) | 底图与点位使用独立 Canvas；悬停只重绘点位层。按 devicePixelRatio 设置实际像素尺寸，以 CSS 像素定义交互距离和标记大小。 |

### 实现

地图使用浅水色、纸色陆地和细海岸线。洲名与海洋名称跟随投影，接近标记时隐藏文字。聚合圆点显示数量，单个物种显示圆心，选中和悬停使用不同描边。合并相邻格子中过近的聚合中心，让标记在同一档位保持间隔。

`canvas-map-renderer.ts` 缓存地理路径，处理两层绘制和屏幕坐标命中检测。平移、缩放与动画通过 `useMapCamera` 的帧订阅重绘；React 只在聚合档位变化及操作结束时更新相机快照，避免重建物种列表。连续输入由 requestAnimationFrame 合并。Canvas 的像素密度上限为 3，减少大屏幕的缓冲区开销；缩放时重新画路径与标记，保持文字和点位尺寸。

点位选择、空白处清除、双击锚点缩放、滚轮、双指缩放、手势中断、区域定位、全屏和列表联动继续使用既有行为。实际鼠标和触屏命中使用 Canvas 的 CSS 坐标；每个聚合点保留原生 HTML 按钮供键盘和读屏访问。聚焦屏幕外点位时先移入视野，再显示预览。

数据仍表示档案的代表坐标，不表示完整分布范围或野外观察记录。没有代表坐标的物种可从列表检索。分类总览保留现有交互。
