# 2026-10-09 拓展动物清单完成归档

本轮目标为新增 100 种动物；累计完成 50 种，动物目录增至 550 种，活动清单剩余 50 种。每种包含物种档案、一张封面和五张观察图。资料和验收见[首批五种记录](todo-expansion-first-five-2026-10-09.md)、[接续十五种记录](todo-expansion-fifteen-2026-10-09.md)、[鸟类与爬行动物十种记录](todo-expansion-ten-2026-10-09.md)、[接续五种记录](todo-expansion-five-2026-10-10.md)、[两栖动物与鲨鱼五种记录](todo-expansion-next-five-2026-10-10.md)、[鱼类五种记录](todo-expansion-fish-five-2026-10-10.md)和[接续鱼类五种记录](todo-expansion-next-fish-five-2026-10-11.md)。

- [x] 双足蚓蜥 *Bipes biporus*：蚓蜥类与仅有前肢的身体。共读：“找找头后面的两只小脚。”
- [x] 大鳗螈 *Siren lacertina*：鳗螈科、外鳃与仅有前肢的身体。共读：“找找头后的小脚和毛刷一样的鳃。”
- [x] 斑点银鲛 *Hydrolagus colliei*：软骨鱼中的全头类。共读：“找找大胸鳍和细长的尾部。”说明银鲛与鲨、鳐的分类差异。
- [x] 强壮海鞘 *Ciona robusta*：固着生活的被囊动物。共读：“找找身体上的两个水管口。”幼体与成体分别标注，复核与 Ciona intestinalis 的旧名混用。
- [x] 海萤 *Vargula hilgendorfii*：介形类的双瓣外壳与发光。共读：“看看像小盒子的外壳。”发光场景与放大身体图分开展示。

- [x] 海地沟齿鼩 *Solenodon paradoxus*：沟齿鼩科与带毒唾液的哺乳动物。共读：“找找细长的鼻尖。”毒液与牙齿结构用资料和示意说明。
- [x] 好望角金毛鼹 *Chrysochloris asiatica*：金毛鼹科的地下生活。共读：“看看前脚挖土的大爪子。”与鼹鼠对照时分别说明分类归属。
- [x] 塞拉亚跗猴 *Tarsius tarsier*：跗猴科的夜行灵长类。共读：“找找大眼睛和抱住树枝的手脚。”制作时核对物种范围与中文名。
- [x] 普通吸血蝠 *Desmodus rotundus*：以血液为食的哺乳动物。共读：“看看它怎样收起翅膀在地面移动。”取食说明交给成人，选用非惊吓性画面。
- [x] 猪鼻蝠 *Craseonycteris thonglongyai*：猪鼻蝠科与微小哺乳动物。共读：“看看鼻子的形状。”身体大小使用可靠尺度参照。
- [x] 大兔唇蝠 *Noctilio leporinus*：水面捕鱼的蝙蝠。共读：“看看它掠过水面时，后脚放在哪里。”用自然捕食影像说明动作。
- [x] 巨獭鼩 *Potamogale velox*：獭鼩科的半水栖生活。共读：“找找侧面扁扁的尾巴。”与水獭分别展示分类归属。
- [x] 中南大羚 *Pseudoryx nghetinhensis*：安南山脉森林中的牛科动物。共读：“沿着两根长角看看尖端。”注明野外记录稀少，重建图不能替代观察证据。
- [x] 草原黏鼠 *Lagostomus maximus*：毛丝鼠科的群居穴居生活。共读：“找找脸上的黑白条纹和洞口。”
- [x] 东部长吻针鼹 *Zaglossus bartoni*：单孔类内部的差异。共读：“比一比它和短吻针鼹的嘴有多长。”产卵与哺乳分别用生活史资料说明。
- [x] 美洲蛇鹈 *Anhinga anhinga*：蛇鹈科与潜水捕鱼。共读：“看看水面上露出的长脖子。”
- [x] 普通潜鸟 *Gavia immer*：潜鸟目与脚的位置。共读：“从侧面找找脚靠近身体的哪里。”用游泳影像解释后置的脚。
- [x] 暴风海燕 *Hydrobates pelagicus*：小型远洋海鸟。共读：“看看它贴近海面时，脚怎样碰到水。”
- [x] 普通鹈燕 *Pelecanoides urinatrix*：鹈燕科的潜水方式。共读：“看看它入水后怎样划动翅膀。”
- [x] 橙脚冢雉 *Megapodius reinwardt*：利用巢丘热量孵卵的鸟。共读：“找找它用脚堆起的土和落叶。”巢丘剖面标注为示意。

- [x] 大响蜜鴷 *Indicator indicator*：响蜜鴷科与人鸟觅食互动。共读：“看看尾巴外侧的浅色羽毛。”引导人寻找蜂巢的行为另附来源。
- [x] 红交嘴雀 *Loxia curvirostra*：交叉鸟嘴与食物专化。共读：“看看上嘴和下嘴怎样交错。”
- [x] 丘鹬 *Scolopax rusticola*：林地涉禽与高位眼睛。共读：“找找长嘴，再找找眼睛靠近头的哪里。”
- [x] 大林鸱 *Nyctibius grandis*：林鸱科与白天的伪装。共读：“在树桩旁找找它的身体轮廓。”
- [x] 茶色蟆口鸱 *Podargus strigoides*：蟆口鸱科与宽嘴。共读：“看看它张嘴时，嘴有多宽。”与猫头鹰分别注明分类归属。
- [x] 瘰鳞蛇 *Acrochordus javanicus*：瘰鳞蛇科的水栖身体。共读：“近看皮肤上颗粒一样的鳞片。”微距注明放大比例。
- [x] 天堂金花蛇 *Chrysopelea paradisi*：无足爬行动物的空中滑翔。共读：“用连续影像看看身体在空中怎样弯曲。”
- [x] 卵食蛇 *Dasypeltis scabra*：专食鸟卵的蛇。共读：“看看嘴怎样围住一枚卵。”内部处理卵壳的结构用示意说明。
- [x] 鼋 *Pelochelys cantorii*：大型鳖类的软壳与沙底生活。共读：“找找宽扁的背和露出沙面的鼻尖。”
- [x] 平胸龟 *Platysternon megacephalum*：平胸龟科的头尾比例。共读：“比一比头、壳和长尾巴。”头部不能完全缩入壳的说明需核对来源。

## 2026-10-10 接续五种

- [x] 黄斑夜蜥 *Lepidophyma flavimaculatum*：夜蜥科与隐蔽生活。共读：“在深色背上找找浅色小斑点。”
- [x] 菲律宾帆蜥 *Hydrosaurus pustulatus*：水边生活与尾部高嵴。共读：“看看背上的嵴怎样延伸到尾巴。”性别与年龄随图注明。
- [x] 斑泥螈 *Necturus maculosus*：成年仍有外鳃的水栖有尾类。共读：“找找四只脚，再看看头旁的外鳃。”与前项比较肢体数量。
- [x] 红背无肺螈 *Plethodon cinereus*：无肺螈科的陆地生活与皮肤呼吸。共读：“看看落叶旁的小身体。”呼吸方式用资料说明。
- [x] 尾蟾 *Ascaphus truei*：急流中的两栖动物。共读：“看看蝌蚪的嘴怎样贴住石头。”成年雄性尾状结构的含义由成人解释。

- [x] 奇异多指节蟾 *Pseudis paradoxa*：蝌蚪与成体大小关系的特殊例子。共读：“在同一比例的图里，比一比蝌蚪和成蛙。”
- [x] 锡兰鱼螈 *Ichthyophis glutinosus*：鱼螈科的无足两栖动物。共读：“沿着身体找找侧面的黄色条纹。”与蛇、蚯蚓分别注明分类。

- [x] 皱鳃鲨 *Chlamydoselachus anguineus*：皱鳃鲨科的长形身体。共读：“找找头后面一排鳃裂。”
- [x] 欧氏尖吻鲨 *Mitsukurina owstoni*：剑吻鲨科与可前伸的颌。共读：“先看看长吻，再用慢镜头看嘴的位置变化。”

## 2026-10-10 接续鱼类五种

资料与验收见[鱼类五种记录](todo-expansion-fish-five-2026-10-10.md)。

- [x] 四眼鱼 *Anableps anableps*：跨越水面的视觉结构。共读：“看看每只眼睛的哪一部分露在水面上。”“四眼”不表示四个眼球。
- [x] 南美肺鱼 *Lepidosiren paradoxa*：肺鱼类的地区与形态差异。共读：“找找细细的成对鳍。”呼吸结构用示意说明。
- [x] 大西洋弹涂鱼 *Periophthalmus barbarus*：潮间带活动与水陆交界。共读：“看看胸鳍怎样撑住身体。”不能把它写成两栖动物。
- [x] 黑鳍冰鱼 *Chaenocephalus aceratus*：南极冰鱼与特殊血液生理。共读：“看看浅色身体和宽大的胸鳍。”缺少血红蛋白的说明需附来源。
- [x] 月鱼 *Lampris guttatus*：深水鱼的体形与产热研究。共读：“找找圆扁的身体和红色鱼鳍。”复核月鱼属修订，不把整个属的记录套给本种。

- [x] 黑叉齿龙鱼 *Chiasmodon niger*：深海鱼的可扩张胃部。共读：“看看细长身体与肚子的轮廓。”不用夸张重建替代摄食记录。
- [x] 达尔文蝙蝠鱼 *Ogcocephalus darwini*：海底用鳍支撑和移动的鱼。共读：“看看身体下方像小脚的鱼鳍。”
- [x] 泥鳅 *Misgurnus anguillicaudatus*：身边淡水鱼与辅助呼吸。共读：“找找嘴周围的小须。”肠呼吸用资料解释。
- [x] 斑点雀鳝 *Lepisosteus oculatus*：雀鳝类与菱形硬鳞。共读：“看看长嘴，再近看身上的鳞片。”
- [x] 塞内加尔多鳍鱼 *Polypterus senegalus*：多鳍鱼类与分开的背鳍。共读：“沿着背找找一片片小鳍。”
