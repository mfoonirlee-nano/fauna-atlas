# 2026-10-09 拓展动物清单完成归档

本轮目标为新增 100 种动物；累计完成 20 种，动物目录增至 520 种，活动清单剩余 80 种。每种包含物种档案、一张封面和五张观察图。资料和验收见[首批五种记录](todo-expansion-first-five-2026-10-09.md)和[接续十五种记录](todo-expansion-fifteen-2026-10-09.md)。

- [x] 双足蚓蜥 *Bipes biporus*：蚓蜥类与仅有前肢的身体。共读：“找找头后面的两只小脚。”
- [x] 大鳗螈 *Siren lacertina*：鳗螈科、外鳃与仅有前肢的身体。共读：“找找头后的小脚和毛刷一样的鳃。”
- [x] 斑点银鲛 *Hydrolagus colliei*：软骨鱼中的全头类。共读：“找找大胸鳍和细长的尾部。”说明银鲛与鲨、鳐的分类差异。
- [x] 强壮海鞘 *Ciona robusta*：固着生活的被囊动物。共读：“找找身体上的两个水管口。”幼体与成体分别标注，复核与 Ciona intestinalis 的旧名混用。
- [x] 海萤 *Vargula hilgendorfii*：介形类的双瓣外壳与发光。共读：“看看像小盒子的外壳。”发光场景与放大身体图分开展示。

- [x] 海地沟齿鼩 *Solenodon paradoxus*：沟齿鼩科与带毒唾液的哺乳动物。共读：“找找细长的鼻尖。”毒液与牙齿结构用资料和示意说明。
- [x] 好望角金毛鼹 *Chrysochloris asiatica*：金毛鼹科的地下生活。共读：“看看前脚挖土的大爪子。”与鼹鼠对照时分别说明分类归属。
- [x] 塞拉亚跗猴 *Tarsius tarsier*：跗猴科的夜行灵长类。共读：“找找大眼睛和抱住树枝的手脚。”制作时核对物种范围与中文名。
- [x] 普通吸血蝠 *Desmodus rotundus*：以血液为食的哺乳动物。共读：“看看它怎样收起翅膀在地面移动。”取食说明交给成人，选用非惊吓性画面。
- [x] 猪鼻蝠 *Craseonycteris thonglongyai*：猪鼻蝠科与微小哺乳动物。共读：“看看鼻子的形状。”身体大小使用可靠尺度参照。
- [x] 大兔唇蝠 *Noctilio leporinus*：水面捕鱼的蝙蝠。共读：“看看它掠过水面时，后脚放在哪里。”用自然捕食影像说明动作。
- [x] 巨獭鼩 *Potamogale velox*：獭鼩科的半水栖生活。共读：“找找侧面扁扁的尾巴。”与水獭分别展示分类归属。
- [x] 中南大羚 *Pseudoryx nghetinhensis*：安南山脉森林中的牛科动物。共读：“沿着两根长角看看尖端。”注明野外记录稀少，重建图不能替代观察证据。
- [x] 草原黏鼠 *Lagostomus maximus*：毛丝鼠科的群居穴居生活。共读：“找找脸上的黑白条纹和洞口。”
- [x] 东部长吻针鼹 *Zaglossus bartoni*：单孔类内部的差异。共读：“比一比它和短吻针鼹的嘴有多长。”产卵与哺乳分别用生活史资料说明。
- [x] 美洲蛇鹈 *Anhinga anhinga*：蛇鹈科与潜水捕鱼。共读：“看看水面上露出的长脖子。”
- [x] 普通潜鸟 *Gavia immer*：潜鸟目与脚的位置。共读：“从侧面找找脚靠近身体的哪里。”用游泳影像解释后置的脚。
- [x] 暴风海燕 *Hydrobates pelagicus*：小型远洋海鸟。共读：“看看它贴近海面时，脚怎样碰到水。”
- [x] 普通鹈燕 *Pelecanoides urinatrix*：鹈燕科的潜水方式。共读：“看看它入水后怎样划动翅膀。”
- [x] 橙脚冢雉 *Megapodius reinwardt*：利用巢丘热量孵卵的鸟。共读：“找找它用脚堆起的土和落叶。”巢丘剖面标注为示意。
