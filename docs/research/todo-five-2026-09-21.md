# 新清单五种动物核验记录

2026-09-21。白掌长臂猿、丽色军舰鸟、药用石龙子、无沟双髻鲨和乌桕大蚕蛾各收录一张封面、五张图库图和六节共读内容。共用仓库现有分类阶元；本次新增长臂猿科、军舰鸟科、石龙子科、双髻鲨科及对应属，乌桕大蚕蛾并入已有天蚕蛾科。

各档案列代表性分布地，不用国家列表代替完整分布图。除大蚕蛾来源明确的翼展上限外，未填缺乏统一口径的体长、体重等数字。全球种群趋势均保留 unknown，独立评估日期未核实，年份留空。

## 白掌长臂猿 · Hylobates lar

观察白色手脚、长臂悬挂、果食、浅色毛型、母婴和鸣叫。深浅毛色均可见于雌雄；单幅双手悬挂图不冒充连续摆荡。全球状态采用 EN。

- [台北市立动物园](https://www.zoo.gov.taipei/News_Content.aspx?n=8A35FDA6483C8C40&s=F2D19E6E4879477A&sms=7BD336E90DA476DA)：分类、白色手脚与脸环。其中国分布记载未当作当前存续种群依据；档案只列东南亚代表地区。
- [哥本哈根动物园](https://www.zoo.dk/en/animal-encyclopedia/white-handed-gibbon)：毛色与性别无固定对应，食性及濒危类别。未采用页面中的极限速度。
- [拉帕尔米尔动物园](https://www.zoo-palmyre.fr/en/birth-lar-gibbon)：幼猿依附母亲、果食、鸣叫与主要威胁。

## 丽色军舰鸟 · Fregata magnificens

观察雄鸟红喉囊、雌鸟白胸、叉尾、飞行取食与幼鸟。成年雌鸟头黑、胸白；幼鸟白头与成年雌鸟的特征不能互换。分类采用鲣鸟目 Suliformes / 军舰鸟科 Fregatidae。全球状态 LC；康奈尔 Watch List 是另一评估体系，不作为 IUCN 类别。

- [康奈尔鸟类实验室：概览](https://www.allaboutbirds.org/guide/Magnificent_Frigatebird)：分类、雌雄差异与叉尾。
- [康奈尔鸟类实验室：生活史](https://www.allaboutbirds.org/guide/Magnificent_Frigatebird/lifehistory)：喉囊展示、水面取食、巢与雌鸟持续育幼、繁殖地威胁。
- [密歇根大学 ADW](https://animaldiversity.org/accounts/Fregata_magnificens/)：IUCN 全球 LC。未引用旧版繁殖对数或把资料发表年份写成评估年份。

## 药用石龙子 · Scincus scincus

观察吻部、短腿、钻沙、探头与小型猎物。沙面步行和沙下摆动是不同运动方式，图库只展示地面可见状态。

- [爬行动物数据库](https://reptile-database.reptarium.cz/Scincus/scincus)：接受学名、Scincidae / Squamata、吻部形态。页面提示分布列表尚未随物种拆分完全更新；不照抄完整国家列表，也不将 S. albifasciatus、S. conirostris 等并入。
- [Maladen 等 2009 年研究](https://arxiv.org/abs/0910.3248)：高速 X 射线显示沙下推进依靠身体和尾巴波动，四肢不承担推进。
- [密歇根大学 ADW](https://animaldiversity.org/accounts/Scincus_scincus/)：形态、沙地生活和食性。其 NE 与当前评估引用冲突；其繁殖段落有推测，未采用。
- [卡塔尔环境部生物多样性系统](https://biodiversity.mecc.gov.qa/en/taxon/1993453)：搜索索引明确列出 IUCN Global Status 为 Least concern；正文抓取返回 502。
- [IUCN 2021 评估 DOI](https://doi.org/10.2305/IUCN.UK.2021-1.RLTS.T164624A1062266.en)：原页未能读取。[Wikispecies 评估引文](https://species.wikimedia.org/wiki/Scincus_scincus)列出作者、2021 版引用及 LC，与上述政府索引一致。本批以此记录 LC，保留间接核验限制，不声称已读独立评估全文。

## 无沟双髻鲨 · Sphyrna mokarran

观察近乎平直、中央有浅缺口的成年头缘、侧端眼睛、高镰形背鳍和不等长尾叶。图像用于初步认识，不作鉴定标本；没有把图像当作电感受器可见证据。

- [佛罗里达自然历史博物馆](https://www.floridamuseum.ufl.edu/discover-fish/species-profiles/great-hammerhead/)：接受名、分类、成年头形、背鳍、食性及分布。页面 2018 年修订并引用旧版保护评估，未采用旧状态。
- [IUCN 2024 全球鲨鳐报告：双髻鲨科](https://portals.iucn.org/library/sites/library/files/documents/2024-024-En_part_10.pdf)：搜索索引的生活史表将 Great Hammerhead / Sphyrna mokarran 列为 Critically Endangered；PDF 正文读取超时。本批采用 CR，未把报告年份当评估年份。
- [Oceana](https://oceana.org/marine-life/great-hammerhead-shark/)：搜索索引同样说明 IUCN CR 与捕捞压力；正文抓取仅返回导航，保留核验限制。

## 乌桕大蚕蛾 · Attacus atlas

观察羽状触角、半透明翅斑、幼虫、茧与停栖成蛾。幼虫吃叶，成蛾口器退化、不再进食；采用 NE，不能将未评估理解为无危。茧图中也有成蛾，说明不同阶段，未声称同一个体连续羽化。

- [马来西亚 MyBIS](https://www.mybis.gov.my/art/281)：学名与天蚕蛾科、雄蛾触角、半透明斑和未评估状态。未采用该页与其他来源不一致的 35 cm 翼展，也未照抄旧贸易提案作为现行规则。
- [伦敦自然历史博物馆](https://www.nhm.ac.uk/discover/spotlight-the-atlas-moth.html)：展翅可达 27 cm，幼虫吃叶、做茧及成蛾不取食。该数值是来源上限；图片非等比例，叶片、树皮只作环境参照。
- [密歇根大学 ADW](https://animaldiversity.org/accounts/Attacus_atlas/)：分类、幼虫蜡质与突起、口器。未混入其他 Attacus 物种的保护类别。

## 图像与验证

内置 image_gen 逐张生成，共保留 30 张 1536×1024 WebP。大蚕蛾首轮封面侵入左侧标题区，编辑后重新检查。各物种目录保存提示词、源图及运行图 SHA-256、目视边界和六视口六动画状态的几何结果。所有图片注明 AI 科学情景重建，不用作精确测量或连续实拍。

采用当前全幅 object-fit: cover 呈现，运行时允许边缘裁切；检查覆盖画布和源构图，不宣称移动端完整全身可见。按项目约定未启动浏览器。

验证结果：`npm run typecheck` 与 `npm run build` 通过；轮播测试 342 项通过。分类及档案加载测试首轮 197 项通过，唯一失败为灵长目旧计数；更新为 9 后该项复测通过。另逐张核对本批 30 张 WebP 的 1536×1024 尺寸、解码、唯一哈希和 README 记录，并核对站内 335 份档案、todo 完成 35 / 待制作 65。
