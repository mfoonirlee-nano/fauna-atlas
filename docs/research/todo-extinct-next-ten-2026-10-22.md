# 十种灭绝动物：E066–E073、E075–E076

2026-10-22 核验。收录两种古鳄形类和八种更新世哺乳动物，每种一份档案、一张封面与五张观察图。沿用 `Historical and fossil evidence` 与 EX，不填独立 IUCN 评估年份，不提供当前活体代表坐标。代表时期与精确灭绝日期分别说明。

## 选题与证据

| 编号 | 物种 | 资料与采用限制 |
| --- | --- | --- |
| E066 | 里奥格兰德恐鳄 *Deinosuchus riograndensis* | [Cossette 与 Brochu 2020](https://doi.org/10.1080/02724634.2020.1767638)核对具体种；[Walter 等2025](https://www.nature.com/articles/s42003-025-07653-4)将恐鳄放在现生鳄类冠群之外，并修订体长估计。不采用影视尺寸，也不把属内物种混用。中文名为依地名区分的档案标签，不声称已核实唯一规范中文名。 |
| E067 | 帝王肌鳄 *Sarcosuchus imperator* | [Sereno 等2001](https://doi.org/10.1126/science.1066521)与[芝加哥大学](https://chronicle.uchicago.edu/011101/supercroc.shtml)支持长吻、鼻端膨大及河流环境。体长由不完整骨骼与现生比较推算，鼻端膨大功能保留未知。 |
| E068 | 真猛犸象 *Mammuthus primigenius* | [NHM](https://www.nhm.ac.uk/discover/were-all-mammoths-woolly.html)与[末期种群研究说明](https://www.nhm.ac.uk/discover/last-mammoths.html)区分大陆与岛屿种群，弗兰格尔岛种群延续到约距今四千年前。毛被、象牙与小耳有遗存依据，单件保存材料不能固定全部个体毛色。 |
| E069 | 披毛犀 *Coelodonta antiquitatis* | [比利时自然科学研究所](https://www.naturalsciences.be/file/cc73d96153bbd5448a56f19d925d05b1379c7f21/70dc922844a77034effd0f51c0b060e27b4e7ac2/dd-e-giants-2023-4.pdf?name=DD_E+Giants_2023_4.pdf&type=application%2Fpdf)、[AMNH](https://research.amnh.org/paleontology/perissodactyl/evolution/groups/rhinocerotidae)与[冻土标本研究](https://av-sher.narod.ru/Biblio/16_boescorov_woolly_rhino.pdf)支持两角与毛被。[2026古基因组研究](https://doi.org/10.1093/gbe/evaf239)使用约14,400年前组织，不能将该样本写成最后一个个体。 |
| E070 | 致命刃齿虎 *Smilodon fatalis* | [佛罗里达博物馆](https://www.floridamuseum.ufl.edu/florida-vertebrate-fossils/species/smilodon-fatalis/)核对形态、物种范围、Leidy 1868及旧异名；[拉布雷亚食物研究](https://tarpits.org/stories/suiting-smilodon)支持当地大型食草动物食性。短尾、粗壮前肢与长上犬齿作为观察重点，毛色、群居和照料伤者保留推测。 |
| E071 | 重型恐狼 *Aenocyon dirus* | [2021古DNA研究](https://doi.org/10.1038/s41586-020-03082-x)及[原团队说明](https://www.qmul.ac.uk/news/latest-news/2021/se/ancient-dna-from-extinct-dire-wolves-reveals-their-unique-evolutionary-history.html)支持重新采用Aenocyon；[2026古基因组研究](https://pubmed.ncbi.nlm.nih.gov/42508403)提出复杂祖源。记录研究差异，不把亲缘关系简化成固定分叉，也不把现代基因编辑灰狼当成本种存活记录。 |
| E072 | 美洲乳齿象 *Mammut americanum* | [伊利诺伊州立博物馆](https://museum.state.il.us/exhibits/larson/mammut.html)、[NPS牙齿比较](https://www.nps.gov/articles/mammoth-or-mastodon.htm)及[馆藏臼齿](https://www.charlestonmuseum.org/research/collection/mammut-americanum-mastodont-tooth/440FF5FD-F344-41F1-8D8B-283318096540)支持齿尖与枝叶食性。[Dooley 等2019](https://doi.org/10.7717/peerj.6614)拆分太平洋乳齿象，不将加利福尼亚旧鉴定材料直接并入本种。 |
| E073 | 大地懒 *Megatherium americanum* | [NHM](https://www.nhm.ac.uk/discover/what-was-megatherium.html)及[菲尔德博物馆骨架](https://mm.fieldmuseum.org/2892526d-cbee-4b7c-9123-9b8b39a30f1d)支持后肢、尾部与植物食性。记录Torres 1787发现及Cuvier 1796命名；足迹与化石测年需按具体遗址理解，不将网页最晚年龄当作无争议灭绝日期。 |
| E075 | 双门齿兽 *Diprotodon optatum* | [澳大利亚博物馆](https://australian.museum/learn/australia-over-time/extinct-animals/diprotodon-optatum/)与[昆士兰博物馆](https://www.museum.qld.gov.au/learn-and-discover/queenslands-ancient-past/meet-the-megafauna/diprotodon-optatum)支持有袋类归属、门齿、骨架和地面活动。两馆概述的晚期时间不同，不采单一年份作为精确灭绝时间。 |
| E076 | 袋狮 *Thylacoleo carnifex* | [澳大利亚博物馆](https://australian.museum/Thylacoleo-carnifex/?s=1&vm=r)与[昆士兰博物馆](https://www.museum.qld.gov.au/learn-and-discover/queenslands-ancient-past/meet-the-megafauna/thylacoleo/)支持切割状前臼齿、门齿、拇指爪及发现史。图中不套用狮鬃或猫科长犬齿；攀爬程度、捕猎场景与毛色仍有限定。 |

E074 *Glyptodon clavipes* 留待制作。[2018修订](https://www.sciencedirect.com/science/article/pii/S0016699517301870)指出其选定模式仅保留后足，种级鉴别需更多材料；[作者机构保存的全文](https://ri.conicet.gov.ar/bitstream/handle/11336/83593/CONICET_Digital_Nro.af157833-c185-464b-9be9-1521d6bcb0f1_A.pdf)记录过往混用不同属尾甲的问题。[2026研究](https://link.springer.com/article/10.1007/s10914-026-09836-0)还重新鉴定了长期归入该种的巴西材料。不能直接用属级复原画面完成一个身份未核定的具体种。本次顺延E076，仍完成十种，E074不勾选。

## 分类采用

[GBIF／PBDB原始查询](../../src/assets/source/todo-extinct-next-ten-taxonomy.json)保存日期、URL和响应，[采用记录](../../src/assets/source/todo-extinct-next-ten-adopted-taxonomy.json)保存最终归属与来源。PBDB的 `ext: 0` 表示非现生，不把数字0误读为现生状态。

- GBIF将两种古鳄形类放入Crocodylia纲、Crocodylidae科，与本批修订研究冲突。按PBDB和论文采用Reptilia纲。恐鳄依据2025研究省略未确定科，不放入现生鳄目；肌鳄采用Pholidosauridae科，所采口径不指定目。沿用ADR 0002与0003的缺失阶元规则，无占位分类单元。
- GBIF将Smilodon fatalis列作异名，档案采用佛罗里达博物馆与PBDB的种级口径。Aenocyon匹配也指向Canis，档案采用原始古DNA研究与PBDB的现组合，旧组合只作检索别名。
- 其余哺乳动物采用GBIF的界、门、纲、目、科、属基线，和PBDB对照。大地懒采用Pilosa目，未混入PBDB中的旧Xenarthra目阶元。
- 不改分类图谱行为。全部档案补齐外形、活动环境、食物、遗存、灭绝记录与独立的发现命名段落，并扩充五主题共读来源记录。

## 图片与静态检查

每种六张WebP位于 `public/images/species/<slug>/`，最终提示词、修订、原图与运行图哈希、尺寸、完整主体边界及逐帧几何位于 `src/assets/source/species/<slug>/`。全部图片使用内置image_gen逐张生成，没有以同一张图裁切充数。

帝王肌鳄、真猛犸象和美洲乳齿象重做初稿封面；帝王肌鳄另补全尾端，并依据Sereno等2001的吻端横向扩展及腹侧偏移描述，修正六张图中不合适的球状膨大。分别检查源PNG与运行WebP联系表，原分辨率检查封面；静态图片栏模拟覆盖390、761、1920、3840宽，几何覆盖九档视口、桌面内容增高160px及六种动画端点。

毛色、软组织、姿态及古环境含推测；生成图不能替代真实化石或馆藏照片，也不能用于测量、计数骨骼或证明行为。未启动GUI或无头浏览器。静态几何和模拟不验证浏览器字体、完整页面排版与实际内容高度。
