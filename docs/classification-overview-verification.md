# 分类总览布局验证

日期：2026-10-16

按用户确认的方案，将单屏面积色块改为可纵向浏览的分类分区，优先支持电脑端。总览按门分区，区内展示下级分类单元及代表动物；缺失纲或目时直接展示下一个有依据的阶元。点击标题或图片卡片进入对应分类，保留完整分类路径，点击具体动物打开物种档案。

图片沿用 `SpeciesSummary.media.image`，通过 `AtlasImage` 延迟加载。卡片以 `object-fit: contain` 展示完整源图；没有封面时显示文字占位。每张分类图片注明代表动物名称，收录数只统计当前筛选结果。

静态图片面板检查使用保留的 WebP：大熊猫、金雕、西印度洋腔棘鱼、科瓦列夫斯基柱头虫。ImageMagick 解码确认四张源图均为 1536 × 1024；检查 170 × 180、260 × 156、140 × 140 面板的等比缩放与居中留白模拟，源图没有裁切，样本动物的身体、羽毛及尾部保持可见。这些模拟不构成全图册的逐像素复核。

验证通过：

- `npm run typecheck`
- `npm run test:atlas-exploration`：22 项，包括所有门的下级组成、代表动物归属、缺失阶元、缺图、筛选、进入与返回、档案打开。
- `npm run test:taxonomy`：233 项。
- `npm run test:taxonomy-explorer`：5 项。
- `npm run test:carousel`：638 项静态与几何检查、8 项交互检查。
- `npm run test:dist-subpath`：生产构建及 5 项路径、目录还原和 JavaScript 预算检查。
- `git diff --check`。

遵循项目约定，未启动 GUI 或无头浏览器。DOM 检查与静态图片模拟无法验证浏览器字体、完整页面排版及实际滚动观感。
