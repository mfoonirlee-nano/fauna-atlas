# 在儿童讲解正文中引用独立解说图

日期：2026-11-11
状态：已采纳

## 背景

用户反馈讲解文字过多，授权生成对应解说图片。已有封面和图集适合外形与环境观察，但不能清楚解释腕骨、孵卵位置或牙齿结构。

## 决定

扩展 ADR 0005：`learning.illustrations` 登记另行验收的解说图，`sections[].images` 引用解说图或公开图集，在相关章节内展示。解说图需要标题、替代文本、说明和生成图标识，另存于 `public/images/learning/`；来源、提示词、返修和验收记录保存在 `src/assets/source/learning/`。每种六张封面与图集的规则保持适用，不把教学示意加入封面轮播。

查看器在既有封面、图集之后追加解说图，保留旧索引，去重并排除待修复素材。正文复用查看器、键盘操作与焦点返回。完整讲解及图片元数据随物种档案按需加载，图片延迟加载。

首批五图由助手对照列明来源并目视核对源图与 WebP，验收范围限制于图注所述教学任务。生成图不作为野外记录或真实标本；独立专家复核、亲子试读仍待完成。

## 验证

数据测试检查章节引用、图片标识和验收哈希；查看器测试检查原有索引、去重和待修复图片排除；DOM 测试检查正文配图、放大及焦点恢复。构建检查资源路径、按需加载及首页脚本预算。测试通过不授予生物学审核状态。
