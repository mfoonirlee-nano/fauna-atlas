# 区分 IUCN 评估与历史、化石灭绝依据

日期：2026-10-19
状态：已采纳

## 背景

大角鹿等已灭绝动物的资料来自化石与博物馆研究，不能将末次化石年代当作 IUCN 评估年份。近代灭绝动物也可能已有政府或博物馆证据，而本次制作没有核实独立 IUCN 评估。

## 决定

物种档案沿用 EX 表达已灭绝，同时以 conservation.system 区分 IUCN Red List 和 Historical and fossil evidence。后者只能搭配 EX，类型禁止填写 assessedYear 和 criteria。assessor 及 sources 说明本档案采用的灭绝依据；不声称未核实的 IUCN 评估。

页面资料区对后者显示“灭绝依据：历史记录或化石研究”。列表、地图和分类图谱继续使用既有 EX 标签。分类图谱仍只表达分类归属。

灭绝年代、末次记录及其限制写入正文与历史统计，不以 assessedYear 代替。历史范围不提供当前活体代表坐标。复原说明继续写入图片 alt、caption、credit 及来源记录。

## 验证

类型检查禁止历史与化石证据携带评估年份或其他状态；档案检查确认 EX、资料来源与年份留空；页面检查确认展示证据说明。全量测试检查目录、分类图谱与按需加载行为。
