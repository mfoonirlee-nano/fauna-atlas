# 省略未确定的科

日期：2026-10-21
状态：已采纳

双嵴龙的 GBIF 匹配给出伤齿龙科。PBDB 没有指定科，Marsh 与 Rowe（2020，doi:10.1017/jpa.2020.14）的研究也没有恢复单系的双嵴龙科。为填满字段而沿用错误归属会误导读者。

扩展 ADR 0002：界、门、属仍必需，纲、目、科在所采用的分类口径未设置或有来源记录的归属未确定时省略。双嵴龙保留界、门、属，省略科；不创建未分类科占位，不将未定阶元类群强填成科。其他已核实的科保持其归属。

分类路径已有跳过缺失阶元的实现。目录仍保留六个位置，用 null 表示缺失阶元；解码后省略相应字段。验证双嵴龙的图谱叶节点、属级上级和生产目录还原。研究记录保留 GBIF、PBDB 差异和采用依据。
