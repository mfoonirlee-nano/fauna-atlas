# 省略分类口径未设置的纲与目

日期：2026-10-13
状态：已采纳

## 背景

本批柱头虫的 GBIF 分类链没有目，铠甲动物的 GBIF、WoRMS 和原始分类研究没有纲。将门名重复写作纲名，或创建一个“未分类目”，会产生资料未支持的分类单元。星虫的 GBIF 记录还保留旧星虫门，WoRMS 则将它归入环节动物门。

## 决定

物种档案必须保留界、门、科、属。纲与目在所用分类口径未设置时省略。分类路径按界、门、纲、目、科、属的顺序仅呈现有依据的分类单元，将下一个存在的阶元连接到上一个存在的阶元，不生成占位分类单元。

共用分类路径承担跳过缺失阶元的逻辑。图谱保留各阶元的固定列位置，档案路径保留每个节点的阶元标签。目录筛选仅列出有依据的纲；没有纲的档案仍可通过所属门、全文搜索与总目录找到。概览标签在没有纲时显示所属门。

压缩目录以空位置保留阶元的序号，解码时省略相应字段，不将后续阶元前移。完整档案与懒加载目录采用同样的缺失字段表示。

分类以现有 GBIF 链为基线；已核实 GBIF 与当前分类差异时，记录对照与采用的修订来源。裸体方格星虫采用 WoRMS 的环节动物门、星虫目和星虫科归属，省略该口径没有设置的纲。学名保留不含亚属括号的双名写法，记录 WoRMS 的亚属表示法。对同名同阶元的中文名称与上级归属仍执行冲突检查。

## 验证

检查缺纲、缺目档案的分类路径与叶节点身份，检查其余完整路径保持原有节点。生产构建的目录还原测试确认缺失字段、科学名称、筛选信息与完整档案一致。用非浏览器测试检查这些档案能进入目录、图谱和档案页面。
