# 以可选儿童讲解逐种迁移物种档案

日期：2026-11-11
状态：已采纳

## 背景

儿童动物百科需要先讲身体、住处和生活，再解释保护与灭绝。现有档案的长文主题不同，直接依赖章节名称或关键词组装页面会误判内容，也无法确保每个问题都有答案。首批五种编辑稿已整理，用户授权接入。

## 决定

在 `Species` 上增加可选的 `learning: SpeciesLearningProfile`。首批五种分别导入自己的内容模块，完整档案仍按需加载；首页摘要不携带儿童讲解。

讲解固定为认识、身体、栖息地、觅食、活动、成长、生态关系、生存处境八节，之后提供观察和可展开的理解题。每节引用该物种来源列表中的 URL，观察图仅引用公开图集，不读取待修复素材。

有讲解的档案首屏突出认识动物，已灭绝和野外灭绝仍在首屏明确标识。详细评估在生存处境一节解释。原有长文、数据、命名故事保留于延伸阅读，没有讲解的动物继续使用原布局。

讲解组件单独延迟加载。页面跳转在当前档案内滚动并移动焦点，不改变应用 hash 路由。图像放大复用既有查看器、键盘操作和焦点返回。

`todo` 中的五种稿件保留为研究快照，正式展示文案以 `src/data/learning` 为准。接入状态与独立专业复核、亲子试读分别记录，不因代码接入而声称科学审核通过。第一阶段盘点识别结构化章节为候选，仍保留待审核状态。

## 验证

类型检查和数据测试验证可选兼容、八节顺序、来源与现有图片。DOM 测试验证目录焦点、回答展开、图像查看器及旧版回退。生产资源测试验证五份讲解随对应档案加载、完整数据往返以及首页预算。

遵循仓库规则不启动浏览器。DOM 与静态样式检查不能代替真实浏览器视觉验收或儿童试读。
