# 区分待核实保护评估与待修复配图

日期：2026-10-27
状态：已采纳

## 背景

十份新档案在没有核实全球保护评估时使用了 IUCN NE，导致卡片、筛选和档案页显示“未评估”。同时，图片的哈希、数量与裁切几何检查曾被误当成生物学验收。

## 决定

- 保留 IucnStatusCode 的正式类别定义，另以 ConservationCode 承载编辑状态 UNVERIFIED。Unverified 分支不允许评估年份或标准，趋势限定 unknown。界面独立显示、筛选“保护评估待核实”，不写成“IUCN 尚未评估”。
- 已撤回的图片存入 pendingMedia.assets，附返修原因。公开 media 仅保留占位说明，不含 image、gallery 或其他待修复图片引用。沿用各视图的分类图形或无图占位；首页轮播不纳入无公开封面的档案。
- 目录摘要仅来自公开 media，独立档案保留 pendingMedia 供编辑处理。图集与图片查看器只读取公开 media，不能回退到待修复素材。
- 每种保留六张原图及其历史提示词、哈希和几何记录，以便追踪与返修；这些记录不再表示生物学合格。TODO 恢复为待制作或返修。
- 恢复配图之前，先完成权威参考对照、结构及位置审核，再完成源图构图、当前 WebP 和各视口验收。不得仅靠免责声明、肢体数量或技术测试恢复发布。

## 验证

检查十种的原始模型、压缩目录、独立档案、实际渲染的状态文字、轮播和档案图集。保留文件完整性与几何测试，并明确它们只验证技术属性。NE 保持独立，已有其他物种的状态不随本次复核改变。
