# 待实现的动物

基于现有 78 个物种档案的分类覆盖现状（哺乳纲 26 / 爬行纲 8 / 两栖纲 4 / 鸟纲 11 / 昆虫纲 6 / 蛛形纲 1 / 刺胞动物门 3〔珊瑚纲 1 / 钵水母纲 1 / 水螅纲 1〕 / 棘皮动物门 2〔海星纲 1 / 海参纲 1〕 / 环节动物门 1〔环带纲 1〕 / 辐鳍鱼纲 4 / 软骨鱼纲 1 / 肉鳍鱼纲 1 / 文昌鱼纲 1 / 七鳃鳗纲 1 / 软甲纲 3 / 肢口纲 1 / 软体动物门 4〔头足纲 2 / 腹足纲 1 / 双壳纲 1〕），
首批 30 种优先补充尚未出现的门、纲与目，并扩充现有薄弱类群。
第二批追加 30 种，侧重鲜明的行为、生态关系与身体机制，当前共 60 种。

## 哺乳动物

- [ ] 土豚 *Orycteropus afer* — 管齿目首次收录；该目仅存的现生种
- [ ] 星鼻鼹 *Condylura cristata* — 真盲缺目首次收录；星形鼻部触器适合展示触觉觅食

## 鸟类

- [ ] 鸮鹦鹉 *Strigops habroptilus* — 鹦形目首次收录；不会飞的夜行鹦鹉与重点保育案例
- [ ] 麝雉 *Opisthocomus hoazin* — 麝雉目首次收录；前肠发酵与幼鸟翼爪形成鲜明特征

## 爬行动物

- [ ] 扬子鳄 *Alligator sinensis* — 短吻鳄科首次收录；与现有鳄科、恒河鳄科物种形成对照
- [ ] 美国毒蜥 *Heloderma suspectum* — 毒蜥科首次收录；补充有毒蜥蜴的物种档案

## 两栖动物

- [ ] 环纹蚓螈 *Siphonops annulatus* — 蚓螈目首次收录；补齐现生两栖动物的三个目
- [ ] 负子蟾 *Pipa pipa* — 负子蟾科首次收录；雌体背部皮肤承担育幼

## 鱼类与其他脊索动物

- [ ] 大西洋盲鳗 *Myxine glutinosa* — 盲鳗纲首次收录；可与现有海七鳃鳗对照无颌类形态
- [ ] 眼斑电鳐 *Torpedo torpedo* — 电鳐目首次收录；扩充目前仅有 1 种的软骨鱼纲
- [ ] 澳洲肺鱼 *Neoceratodus forsteri* — 肺鱼类首次收录；可与现有矛尾鱼对照肉鳍鱼纲现生类群
- [ ] 大西洋火体虫 *Pyrosoma atlanticum* — 海樽纲首次收录；补充群体生活的被囊动物

## 无脊椎动物

### 尚未收录的门

- [ ] 阿氏偕老同穴 *Euplectella aspergillum* — 多孔动物门首次收录；六放海绵纲代表
- [ ] 淡海栉水母 *Mnemiopsis leidyi* — 栉水母动物门首次收录；可与刺胞动物门水母对照
- [ ] 日本三角涡虫 *Dugesia japonica* — 扁形动物门首次收录；再生研究常用物种
- [ ] 秀丽隐杆线虫 *Caenorhabditis elegans* — 线虫动物门首次收录；经典模式动物
- [ ] 鸭嘴海豆芽 *Lingula anatina* — 腕足动物门首次收录；可与双壳类对照外形和身体结构
- [ ] 总合草苔虫 *Bugula neritina* — 苔藓动物门首次收录；补充固着群体动物

### 节肢动物门

- [ ] 秘鲁巨人蜈蚣 *Scolopendra gigantea* — 唇足纲首次收录；大型多足捕食者代表
- [ ] 非洲巨人马陆 *Archispirostreptus gigas* — 倍足纲首次收录；补充腐食型多足动物
- [ ] 帝王蝎 *Pandinus imperator* — 蝎目首次收录；扩充目前仅有 1 种的蛛形纲
- [ ] 大型溞 *Daphnia magna* — 鳃足纲首次收录；淡水食物网与生态毒理研究代表
- [ ] 雀尾螳螂虾 *Odontodactylus scyllarus* — 口足目首次收录；与十足目、磷虾目形成软甲纲内对照
- [ ] 十七年蝉 *Magicicada septendecim* — 半翅目首次收录；17 年周期生活史扩充昆虫纲

### 软体动物门

- [ ] 橡胶靴石鳖 *Cryptochiton stelleri* — 多板纲首次收录；展示八枚背板与宽大外套带
- [ ] 普通角贝 *Antalis vulgaris* — 掘足纲首次收录；补充管状贝壳与掘穴生活型

### 环节动物门

- [ ] 巨型管虫 *Riftia pachyptila* — 多毛纲首次收录；深海热液生态与化能共生代表

### 棘皮动物门

- [ ] 紫海胆 *Strongylocentrotus purpuratus* — 海胆纲首次收录；补充啃食藻类的礁区底栖动物
- [ ] 脆刺蛇尾 *Ophiothrix fragilis* — 蛇尾纲首次收录；可与现有海星对照腕部运动方式
- [ ] 海羊齿 *Antedon bifida* — 海百合纲首次收录；补充羽状腕滤食型棘皮动物

## 第二批：奇特行为与身体机制

### 哺乳动物

- [ ] 指猴 *Daubentonia madagascariensis* — 指猴科首次收录；敲击树干定位虫道，再用细长中指掏取幼虫
- [ ] 南方三带犰狳 *Tolypeutes matacus* — 能把头尾严密扣合，将身体闭成近乎完整的甲球
- [ ] 马来鼯猴 *Galeopterus variegatus* — 皮翼目首次收录；颈部、四肢与尾部之间的大面积翼膜承担林冠滑翔
- [ ] 裸鼹鼠 *Heterocephalus glaber* — 单一繁殖雌性与分工成员组成地下群落，是罕见的真社会性哺乳动物

### 鸟类

- [ ] 华丽琴鸟 *Menura novaehollandiae* — 雄鸟能把多种鸟鸣和环境声音编入求偶展示
- [ ] 油鸱 *Steatornis caripensis* — 夜间以果实为食，并用人耳可听见的点击声在黑暗洞穴中回声定位
- [ ] 双角犀鸟 *Buceros bicornis* — 雌鸟封闭树洞巢口，只留下由雄鸟递送食物的窄缝
- [ ] 鲸头鹳 *Balaeniceps rex* — 长时间静止伏击，再用鞋形巨喙突然夹住肺鱼等猎物

### 爬行动物

- [ ] 澳洲棘蜥 *Moloch horridus* — 皮肤表面的微细沟槽能把身体接触到的水引向口部
- [ ] 德州角蜥 *Phrynosoma cornutum* — 遭遇部分捕食者时可从眼周喷血，以气味和味道逼退对方
- [ ] 蛛尾拟角蝰 *Pseudocerastes urarachnoides* — 摆动蜘蛛状尾尖，引诱食虫鸟进入伏击距离

### 两栖动物

- [ ] 壮发蛙 *Trichobatrachus robustus* — 折断趾骨末端，让尖骨刺穿皮肤形成临时防御爪
- [ ] 紫蛙 *Nasikabatrachus sahyadrensis* — 大部分时间在地下活动，只在季风繁殖期短暂现身
- [ ] 达尔文蛙 *Rhinoderma darwinii* — 雄蛙把蝌蚪收入鸣囊，直到幼体变态为小蛙

### 鱼类

- [ ] 大鳍后肛鱼 *Macropinna microstoma* — 透明头罩内的管状眼睛能从朝上转向朝前
- [ ] 叶海龙 *Phycodurus eques* — 叶片状附肢模拟漂动海藻，雄鱼在尾部携带受精卵
- [ ] 电鳗 *Electrophorus electricus* — 用弱放电完成电定位，以强放电捕猎和防御
- [ ] 白斑河鲀 *Torquigener albomaculosus* — 雄鱼在海床筑出直径约 2 米的放射状沙圈作为求偶巢
- [ ] 射水鱼 *Toxotes jaculatrix* — 从水下喷射水柱击落枝叶上的昆虫，并补偿水面折射造成的瞄准偏差

### 尚未收录的门

- [ ] 龙猫栉蚕 *Eoperipatus totoro* — 有爪动物门首次收录；从口侧乳突交叉喷出黏液束缚猎物
- [ ] 拉氏熊虫 *Ramazzottius varieornatus* — 缓步动物门首次收录；脱水时缩成隐生体，复水后可恢复活动
- [ ] 黏丝盘虫 *Trichoplax adhaerens* — 扁盘动物门首次收录；没有神经元、肌肉和器官，仍能协调运动与取食
- [ ] 巨纵沟纽虫 *Lineus longissimus* — 纽形动物门首次收录；能从头部翻出独立长吻捕猎

### 节肢动物门

- [ ] 缩头鱼虱 *Cymothoa exigua* — 吸食使鱼舌萎缩后占据原位，形成近似替代舌的结构
- [ ] 美洲巨鞭蝎 *Mastigoproctus giganteus* — 外形似蝎却没有毒针，受威胁时会喷出带醋酸气味的防御液
- [ ] 蟹奴 *Sacculina carcini* — 成体在蟹体内扩展根状组织，外部只留下承担繁殖的囊体

### 软体动物门

- [ ] 鳞足螺 *Chrysomallon squamiferum* — 足部覆有鳞片，部分种群把硫化铁沉积进外壳和鳞片
- [ ] 幽灵蛸 *Vampyroteuthis infernalis* — 在低氧深海翻起腕间膜包裹身体，并释放发光黏液防御

### 其他无脊椎动物

- [ ] 澳大利亚箱水母 *Chironex fleckeri* — 拥有 24 只眼，其中 8 只带晶状体，能依靠视觉主动避障
- [ ] 博比特虫 *Eunice aphroditois* — 身体埋在海床中，以快速张合的颚伏击游近的猎物
