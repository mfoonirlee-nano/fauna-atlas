## 选题与共读方式

目标是帮助孩子认识地球上动物的多样性：有的长毛，有的有壳；有的在树上荡，有的在沙里钻，还有的固定在海底生活。选题同时考虑身体结构、行动方式、生活环境和生长变化，避免只靠相似动物的细小花纹扩充数量。

- 每份物种档案先讲一个能看见的特点，用主体清楚的图片和一句短话表达。下列引号内是亲子观察提示，家长可以跟着孩子的兴趣展开。
- 共读时可以先叫“鸟”“小鱼”“虫子”，再介绍具体名字；学名供制作时定位物种，不要求孩子记忆、认字或完成问答。
- 动作选题使用连续图或前后对照图；大小比较统一比例，微距照片标明参照物。只在雄性、雌性或某个生长阶段出现的特点，要在图片与说明中写清。
- 每次挑一两种，也可以配已有动物一起看，例如用大食蚁兽与土豚比较长嘴，用蛞蝓与蜗牛比较外壳。制作时交替选择不同组，避免连续堆叠近似物种。
- 分组供家长选内容，分类图谱仍按仓库分类口径维护。“其他水边与海中动物”包含多个动物门，不作为一个分类单元。
- 下列名称与观察点用于选题。制作物种档案时，逐项核实中文名、接受学名、分布、行为和图像，尤其注意蜜袋鼯、枯叶龟等涉及物种拆分的范围。

## 哺乳动物（20 种）

从草地、森林、沙漠到寒冷地区，看看长毛的动物怎样用不同的身体部位生活。

- [x] 大食蚁兽 *Myrmecophaga tridactyla*：长嘴与取食。“看看它从长嘴里伸出的细舌头。”
- [x] 鬃狼 *Chrysocyon brachyurus*：高草中的长腿。“找找草丛上方的身体和下面的长腿。”
- [ ] 熊狸 *Arctictis binturong*：能抓握的尾巴。“看看它怎样把尾巴绕在树枝上。”
- [ ] 马岛獴 *Cryptoprocta ferox*：树间平衡。“看看它沿树枝走时，长尾巴放在哪里。”
- [ ] 长鼻猴 *Nasalis larvatus*：雄性的鼻子。“找找成年雄猴垂下来的大鼻子。”
- [ ] 山魈 *Mandrillus sphinx*：脸部外形。“看看成年雄猴鼻子两边的蓝色和中间的红色。”
- [ ] 白掌长臂猿 *Hylobates lar*：悬挂与摆荡。“看看它怎样用长胳膊从一根树枝荡到另一根。”
- [ ] 东非黑白疣猴 *Colobus guereza*：长毛与身体轮廓。“找找身体两侧垂下的白色长毛。”
- [ ] 金狮狨 *Leontopithecus rosalia*：小型树栖动物。“看看它脸旁一圈金色的毛。”
- [ ] 袋獾 *Sarcophilus harrisii*：低矮体形。“找找黑色身体、短腿和胸前的白色花纹。”
- [ ] 袋食蚁兽 *Myrmecobius fasciatus*：林地取食。“看看它把尖嘴伸向地面寻找白蚁。”
- [ ] 马氏树袋鼠 *Dendrolagus matschiei*：树上的袋鼠。“看看它怎样抱住树干往上爬。”
- [ ] 蜜袋鼯 *Petaurus breviceps*：滑翔的皮膜。“看看它张开四肢时，身体两侧展开的皮膜。”
- [ ] 印度狐蝠 *Pteropus medius*：哺乳动物的翅膀。“看看它倒挂休息时怎样把翅膀收起来。”
- [ ] 南非豪猪 *Hystrix africaeaustralis*：长刺。“找找背上和尾部粗细不同的刺。”
- [ ] 跳兔 *Pedetes capensis*：前后腿的差异。“看看短短的前腿和用来跳跃的长后腿。”
- [ ] 麝牛 *Ovibos moschatus*：寒冷地区的长毛。“看看长毛怎样垂到腿旁边。”
- [ ] 驼鹿 *Alces alces*：雄性的掌状角。“找找成年雄鹿头上像大手掌一样展开的角。”
- [ ] 单峰驼 *Camelus dromedarius*：沙地上的脚。“看看宽宽的脚怎样踩在沙地上。”
- [ ] 长颈羚 *Litocranius walleri*：站立取食。“看看它用后腿站起来，伸长脖子吃叶子。”

## 鸟类（15 种）

用嘴、脚和巢的差异认识鸟，兼顾水边、草原、森林和海上的生活。

- [x] 蛇鹫 *Sagittarius serpentarius*：地面行走。“看看这只鸟怎样迈着长腿走过草地。”
- [x] 白琵鹭 *Platalea leucorodia*：匙形嘴。“找找嘴巴末端像小勺一样变宽的地方。”
- [ ] 黑翅长脚鹬 *Himantopus himantopus*：浅水长腿。“看看它站在浅水里时，身体离水面有多高。”
- [ ] 反嘴鹬 *Recurvirostra avosetta*：向上弯的嘴。“沿着细嘴巴，看看尖端朝哪边弯。”
- [ ] 白鹈鹕 *Pelecanus onocrotalus*：嘴下的喉囊。“看看它捕鱼时嘴巴下面张开的袋子。”
- [ ] 蓝脚鲣鸟 *Sula nebouxii*：有蹼的脚。“看看蓝色脚趾之间连着的蹼。”
- [ ] 丽色军舰鸟 *Fregata magnificens*：雄性的喉囊。“看看雄鸟鼓起来的红色喉囊。”
- [ ] 美洲水雉 *Jacana jacana*：浮叶上的长趾。“找找踩在水面叶子上的细长脚趾。”
- [ ] 黑头织布鸟 *Ploceus cucullatus*：编织鸟巢。“看看它用嘴叼着草条，把巢编在树枝上。”
- [ ] 缎蓝园丁鸟 *Ptilonorhynchus violaceus*：求偶场地。“找找雄鸟搭的草茎通道和旁边的蓝色物件。”
- [ ] 华丽极乐鸟 *Cicinnurus magnificus*：雄性的尾羽。“看看雄鸟尾后两根弯弯的长羽毛。”
- [ ] 大走鹃 *Geococcyx californianus*：奔跑的鸟。“看看它在地上跑时伸出的长尾巴。”
- [ ] 穴小鸮 *Athene cunicularia*：地洞旁的生活。“在地面洞口旁找找站着的小鸮。”

- [ ] 日鳽 *Eurypyga helias*：展开与收拢的翅膀。“看看翅膀展开后露出的两块大花纹。”

- [ ] 弗氏玻璃蛙 *Hyalinobatrachium fleischmanni*：半透明腹部。“从下方看看肚皮里透出的身体轮廓。”
- [x] 番茄蛙 *Dyscophus antongilii*：圆鼓的体形。“看看成年雌蛙红红的背和圆圆的身体。”

## 制作提示与资料入口

观察点应使用自然行为画面。例如刺鲀鼓起身体用已有影像说明，制作时不为取景刺激动物；园丁鸟的求偶场地与育雏巢要分开介绍；船蛸的白壳要说明是雌性形成的卵壳。

本轮按已有档案去重，并查阅部分机构资料辅助选题；以下资料不代表已完成 100 种动物的逐种事实核验。正式制作时沿用仓库的物种研究与图像核验流程。

- 长颈羚站立取食的观察点参考[圣迭戈动物园：羚羊](https://animals.sandiegozoo.org/animals/antelope)。
- 袋食蚁兽选题参考[珀斯动物园：Numbat](https://perthzoo.wa.gov.au/animal/numbat)。
- 刺竹节虫的叶片状外形参考[珀斯动物园：Spiny Leaf Insect](https://perthzoo.wa.gov.au/animal/spiny-leaf-insect)。
- 海笔群体与附着生活的观察方向参考[蒙特雷湾水族馆：Sea pen](https://www.montereybayaquarium.org/animals-the-ocean/animals-a-to-z/sea-pen)。
