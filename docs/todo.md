# 待实现的动物

基于现有 78 个物种档案的分类覆盖现状（哺乳纲 26 / 爬行纲 8 / 两栖纲 4 / 鸟纲 11 / 昆虫纲 6 / 蛛形纲 1 / 刺胞动物门 3〔珊瑚纲 1 / 钵水母纲 1 / 水螅纲 1〕 / 棘皮动物门 2〔海星纲 1 / 海参纲 1〕 / 环节动物门 1〔环带纲 1〕 / 辐鳍鱼纲 4 / 软骨鱼纲 1 / 肉鳍鱼纲 1 / 文昌鱼纲 1 / 七鳃鳗纲 1 / 软甲纲 3 / 肢口纲 1 / 软体动物门 4〔头足纲 2 / 腹足纲 1 / 双壳纲 1〕），
优先补充尚未出现的门、纲与目，并扩充现有薄弱类群，共 30 种。

## 哺乳动物

- [ ] 土豚 *Orycteropus afer* — 管齿目首次收录；该目仅存的现生种
- [ ] 星鼻鼹 *Condylura cristata* — 真盲缺目首次收录；星形鼻部触器适合展示触觉觅食

## 鸟类

- [ ] 鸮鹦鹉 *Strigops habroptilus* — 鹦形目首次收录；不会飞的夜行鹦鹉与重点保育案例
- [ ] 麝雉 *Opisthocomus hoazin* — 麝雉目首次收录；前肠发酵与幼鸟翼爪形成鲜明特征

## 爬行动物

- [ ] 扬子鳄 *Alligator sinensis* — 短吻鳄科首次收录；与现有鳄科、恒河鳄科物种形成对照
- [ ] 美国毒蜥 *Heloderma suspectum* — 毒蜥科首次收录；补充有毒蜥蜴的物种档案

## 两栖动物

- [ ] 环纹蚓螈 *Siphonops annulatus* — 蚓螈目首次收录；补齐现生两栖动物的三个目
- [ ] 负子蟾 *Pipa pipa* — 负子蟾科首次收录；雌体背部皮肤承担育幼

## 鱼类与其他脊索动物

- [ ] 大西洋盲鳗 *Myxine glutinosa* — 盲鳗纲首次收录；可与现有海七鳃鳗对照无颌类形态
- [ ] 眼斑电鳐 *Torpedo torpedo* — 电鳐目首次收录；扩充目前仅有 1 种的软骨鱼纲
- [ ] 澳洲肺鱼 *Neoceratodus forsteri* — 肺鱼类首次收录；可与现有矛尾鱼对照肉鳍鱼纲现生类群
- [ ] 大西洋火体虫 *Pyrosoma atlanticum* — 海樽纲首次收录；补充群体生活的被囊动物

## 无脊椎动物

### 尚未收录的门

- [ ] 阿氏偕老同穴 *Euplectella aspergillum* — 多孔动物门首次收录；六放海绵纲代表
- [ ] 淡海栉水母 *Mnemiopsis leidyi* — 栉水母动物门首次收录；可与刺胞动物门水母对照
- [ ] 日本三角涡虫 *Dugesia japonica* — 扁形动物门首次收录；再生研究常用物种
- [ ] 秀丽隐杆线虫 *Caenorhabditis elegans* — 线虫动物门首次收录；经典模式动物
- [ ] 鸭嘴海豆芽 *Lingula anatina* — 腕足动物门首次收录；可与双壳类对照外形和身体结构
- [ ] 总合草苔虫 *Bugula neritina* — 苔藓动物门首次收录；补充固着群体动物

### 节肢动物门

- [ ] 秘鲁巨人蜈蚣 *Scolopendra gigantea* — 唇足纲首次收录；大型多足捕食者代表
- [ ] 非洲巨人马陆 *Archispirostreptus gigas* — 倍足纲首次收录；补充腐食型多足动物
- [ ] 帝王蝎 *Pandinus imperator* — 蝎目首次收录；扩充目前仅有 1 种的蛛形纲
- [ ] 大型溞 *Daphnia magna* — 鳃足纲首次收录；淡水食物网与生态毒理研究代表
- [ ] 雀尾螳螂虾 *Odontodactylus scyllarus* — 口足目首次收录；与十足目、磷虾目形成软甲纲内对照
- [ ] 十七年蝉 *Magicicada septendecim* — 半翅目首次收录；17 年周期生活史扩充昆虫纲

### 软体动物门

- [ ] 橡胶靴石鳖 *Cryptochiton stelleri* — 多板纲首次收录；展示八枚背板与宽大外套带
- [ ] 普通角贝 *Antalis vulgaris* — 掘足纲首次收录；补充管状贝壳与掘穴生活型

### 环节动物门

- [ ] 巨型管虫 *Riftia pachyptila* — 多毛纲首次收录；深海热液生态与化能共生代表

### 棘皮动物门

- [ ] 紫海胆 *Strongylocentrotus purpuratus* — 海胆纲首次收录；补充啃食藻类的礁区底栖动物
- [ ] 脆刺蛇尾 *Ophiothrix fragilis* — 蛇尾纲首次收录；可与现有海星对照腕部运动方式
- [ ] 海羊齿 *Antedon bifida* — 海百合纲首次收录；补充羽状腕滤食型棘皮动物
