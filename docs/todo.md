# 待实现的动物

本批计划新增 31 种动物，已按学名与现有物种档案核对，未重复收录。选题侧重孩子熟悉的形象、圆润或毛茸茸的外形、鲜艳的颜色，以及便于观察的动作。以下说明作为后续制作的内容切入点，具体知识与分类信息在制作物种档案时核实。

## 哺乳动物（18 种）

- [ ] 水豚 *Hydrochoerus hydrochaeris* — 从圆鼻子、小耳朵和水边生活切入，认识“卡皮巴拉”
- [ ] 考拉 *Phascolarctos cinereus* — 观察毛茸茸的耳朵、大鼻子和抱住树干的姿势
- [ ] 耳廓狐 *Vulpes zerda* — 用醒目的大耳朵引出沙漠生活
- [ ] 北极狐 *Vulpes lagopus* — 对比冬夏毛色，观察它在雪地里的样子
- [ ] 欧亚红松鼠 *Sciurus vulgaris* — 观察蓬松的大尾巴、攀树动作和抱着食物的前爪
- [ ] 穴兔 *Oryctolagus cuniculus* — 从长耳朵和蹦跳动作切入，介绍家兔的野生祖先
- [ ] 豚鼠 *Cavia porcellus* — 观察圆滚滚的身体、小短腿和不同叫声
- [ ] 金仓鼠 *Mesocricetus auratus* — 从鼓起的颊囊切入，认识它搬运食物的方式
- [ ] 毛丝鼠 *Chinchilla lanigera* — 观察大耳朵、浓密绒毛和沙浴动作
- [ ] 羊驼 *Vicugna pacos* — 从毛茸茸的身体和长脖子切入，练习辨认羊驼与美洲驼
- [ ] 袋熊 *Vombatus ursinus* — 观察粗壮身体与挖洞动作，认识澳大利亚的穴居动物
- [ ] 短尾矮袋鼠 *Setonix brachyurus* — 从看起来像微笑的脸部外形切入，认识小型袋鼠
- [ ] 西欧刺猬 *Erinaceus europaeus* — 观察尖刺、小鼻子和蜷成球的防御姿势
- [ ] 港海豹 *Phoca vitulina* — 观察胡须、鳍肢，以及在岸上和水中的不同动作
- [ ] 加州海狮 *Zalophus californianus* — 从外耳和前鳍切入，练习区分海狮与海豹
- [ ] 白鲸 *Delphinapterus leucas* — 观察圆额头、白色身体，并聆听水下叫声
- [ ] 虎鲸 *Orcinus orca* — 辨认黑白花纹、背鳍和成群游动的身影
- [ ] 驯鹿 *Rangifer tarandus* — 从童话里熟悉的形象切入，观察鹿角和雪地行走

## 鸟类（7 种）

- [ ] 大西洋海鹦 *Fratercula arctica* — 观察彩色鸟喙、黑白羽毛和潜水动作
- [ ] 小蓝企鹅 *Eudyptula minor* — 从蓝灰色羽毛与小体型切入，对比已有的帝企鹅
- [ ] 鸡尾鹦鹉 *Nymphicus hollandicus* — 观察头顶羽冠和脸颊色斑，聆听口哨般的叫声
- [ ] 绯红金刚鹦鹉 *Ara macao* — 用红、黄、蓝的羽毛配色引导观察翅膀与长尾
- [ ] 蓝孔雀 *Pavo cristatus* — 观察开屏时的眼状斑纹，与已有的绿孔雀作比较
- [ ] 疣鼻天鹅 *Cygnus olor* — 从弯曲的长脖子、白羽和水面游姿切入
- [ ] 绿头鸭 *Anas platyrhynchos* — 观察公母羽色差异，联系公园水边常见的鸭子

## 爬行动物（3 种）

- [ ] 豹纹守宫 *Eublepharis macularius* — 观察豹纹般的斑点、眼睑和粗尾巴
- [ ] 滑龟 *Trachemys scripta* — 以孩子熟悉的红耳龟亚种为例，观察眼后色斑、龟壳和晒背姿势
- [ ] 亚达伯拉象龟 *Aldabrachelys gigantea* — 从巨大的龟壳与缓慢步态切入，对比陆龟和海龟

## 鱼类（3 种）

- [ ] 拟刺尾鲷 *Paracanthurus hepatus* — 从“多莉”的蓝色身体、黑色花纹和黄色尾鳍切入
- [ ] 孔雀鱼 *Poecilia reticulata* — 观察扇形尾鳍和多样颜色，认识常见观赏鱼
- [ ] 黄海马 *Hippocampus kuda* — 观察马头般的头部、卷曲尾巴和直立游姿
