# 动物制作清单：面向 3 岁孩子的 50 种选题

这份清单记录 50 种候选动物，已完成 43 种，剩余 7 种待制作。选题目标是让她愿意看、能指认一个身体特点，并从动物的动作和生活场景认识世界。优先级是本项目的内容安排，不是年龄测评或学习进度要求。

## 制作与共读方式

- 每份物种档案先突出一个特点，用一张主体清楚的图片和一句短话表达；其他知识留给家长展开。
- 共读时先用“兔子”“海星”等熟悉称呼引入，档案保留下列物种名和学名，不要求孩子背诵。
- 图片展示完整身体或清楚的局部；动作使用连续图或前后对照图。涉及大小比较时统一比例，并给出参照物。
- 以下引号内是亲子观察提示。家长可以跟着她的指认继续聊，不必逐题提问或要求回答正确。
- 先认识一种动物，再按兴趣比较一个明显差别。不要连续制作多种仅靠细小花纹区分的动物。
- 声音可作为以后补充的材料；当前选题用图片也能讲清。用真实动物行为写内容，避免把表情解释成人类情绪。
- 已收录的大象、长颈鹿、狮子、老虎、金鱼、蝴蝶等可搭配共读，不必等本清单制作完成。

斑胸草雀采用拆分后的澳大利亚种 *Taeniopygia castanotis*，旧合并学名 *T. guttata* 的处理见[本批核验记录](research/five-animals-blue-tit-to-alligator-2026-09-17.md)。
