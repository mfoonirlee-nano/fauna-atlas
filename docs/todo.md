## 选题与共读方式

本轮补充动物的身体结构、生活史和栖息环境：没有脊柱的脊索动物、缺少部分肢体的脊椎动物、固着与群体生活的动物、寄生动物，以及沙粒间和显微镜下的多细胞动物。查阅者可以从熟悉的鸟兽走向这些类群，了解动物界包含的不同生活方式。

面向 3 岁左右孩子，每次选一两种，先找图中可见的特点；成人再读分类、呼吸、取食与生活史说明。每项包含具体物种、补充方向和共读观察提示。

- 下表是制作分组，包含纲、门和观察主题等不同口径，不作为分类阶元。分类图谱仍按项目统一的分类口径建立归属关系，也不表示演化时间或祖先关系。
- 学名用于定位物种；中文名为选题标签。少见类群暂用类群名或描述性标签，制作时核实中文通名，不把暂用标签写成规范名称。接受学名、完整分类链、分布和行为须在制作档案时逐项复核。
- 显微动物仍属于动物。细菌、真菌和单细胞真核生物继续放在独立微生物专题，不进入动物搜索、封面轮播或分类图谱。
- 区分单个动物、群体、宿主和共生者；幼体与成体、雌雄、不同季节分别标注。用连续自然影像展示动作，不能从静止图片推断运动方式。
- 微距、显微图和内部结构示意注明尺度；AI 重建、人工着色和非实测比例分别说明。没有肺、血红蛋白或某种肢体的说明需要资料支持，不能单凭外观判断。
- 用自然行为影像，不为拍照惊吓、翻动或刺激动物。寄生、毒液和病原相关选题由成人解释生活史，采用示意图或研究影像，不安排捕捉、培养、接触宿主或诱发防御行为。
- 制作每种动物时，按[物种图片与封面规则](../src/assets/source/README.md#species-image-set-rule)完成物种档案、一张封面、五张观察图、来源与验收，再勾选并移入完成归档。

## 鱼类与其他脊索动物（11 种）

前 10 项为鱼类；最后 1 项为被囊动物。后者属于脊索动物门，没有脊柱，制作时不得归入鱼类。

- [ ] 四眼鱼 *Anableps anableps*：跨越水面的视觉结构。共读：“看看每只眼睛的哪一部分露在水面上。”“四眼”不表示四个眼球。
- [ ] 南美肺鱼 *Lepidosiren paradoxa*：肺鱼类的地区与形态差异。共读：“找找细细的成对鳍。”呼吸结构用示意说明。
- [ ] 大西洋弹涂鱼 *Periophthalmus barbarus*：潮间带活动与水陆交界。共读：“看看胸鳍怎样撑住身体。”不能把它写成两栖动物。
- [ ] 黑鳍冰鱼 *Chaenocephalus aceratus*：南极冰鱼与特殊血液生理。共读：“看看浅色身体和宽大的胸鳍。”缺少血红蛋白的说明需附来源。
- [ ] 月鱼 *Lampris guttatus*：深水鱼的体形与产热研究。共读：“找找圆扁的身体和红色鱼鳍。”复核月鱼属修订，不把整个属的记录套给本种。
- [ ] 黑叉齿龙鱼 *Chiasmodon niger*：深海鱼的可扩张胃部。共读：“看看细长身体与肚子的轮廓。”不用夸张重建替代摄食记录。
- [ ] 达尔文蝙蝠鱼 *Ogcocephalus darwini*：海底用鳍支撑和移动的鱼。共读：“看看身体下方像小脚的鱼鳍。”
- [ ] 泥鳅 *Misgurnus anguillicaudatus*：身边淡水鱼与辅助呼吸。共读：“找找嘴周围的小须。”肠呼吸用资料解释。
- [ ] 斑点雀鳝 *Lepisosteus oculatus*：雀鳝类与菱形硬鳞。共读：“看看长嘴，再近看身上的鳞片。”
- [ ] 塞内加尔多鳍鱼 *Polypterus senegalus*：多鳍鱼类与分开的背鳍。共读：“沿着背找找一片片小鳍。”
- [ ] 巨型尾海鞘（中文名待核） *Bathochordaeus mcnutti*：终生保留尾部的被囊动物与黏液滤食房。共读：“找找透明房子里的小身体和尾巴。”房子大小不能当作身体大小。[行为依据：MBARI](https://annualreport.mbari.org/2018/story/discovering-animals-never-seen-before)。

## 昆虫与其他节肢动物（19 种）

前 10 项为昆虫。后 9 项补充弹尾、原尾、双尾、甲壳、蛛形、海蜘蛛和多足等类群；六足动物的内部归属在制作分类链时核实。

- [ ] 丹麦蜉蝣 *Ephemera danica*：蜉蝣目与水生若虫、空中成虫的转换。共读：“找找尾端的细丝和竖起的翅膀。”
- [ ] 加州大石蝇 *Pteronarcys californica*：襀翅目与溪流生活。共读：“看看翅膀平放在背上的样子。”若虫另图标注。
- [ ] 月斑石蛾 *Limnephilus lunatus*：毛翅目与幼虫携带的巢筒。共读：“看看幼虫住的小筒由什么材料拼成。”成虫、幼虫分开展示。
- [ ] 普通蝎蛉 *Panorpa communis*：长翅目与雄性尾端外形。共读：“找找长长的嘴部和尾端。”弯曲尾端是生殖结构，不能画成毒刺。
- [ ] 蛇蛉 *Raphidia ophiopsis*：蛇蛉目与延长的前胸。共读：“看看头后面细长的那一段。”
- [ ] 捻翅虫 *Mengenilla chobauti*：捻翅目与寄生生活史。共读：“对照雌雄图，找找哪一只有翅膀。”本种雌性形态须单独核实，不能套用其他捻翅虫的宿主体内形态。
- [ ] 欧洲蝼蛄 *Gryllotalpa gryllotalpa*：挖掘型前足。共读：“看看前脚像不像小铲子。”
- [ ] 喷炮步甲 *Brachinus crepitans*：防御分泌与步甲科。共读：“找找橙色前半身和深色背部。”防御机制用示意说明，不刺激动物喷射。
- [ ] 豌豆蚜 *Acyrthosiphon pisum*：刺吸取食与不同繁殖阶段。共读：“找找腹部后方的两根小管。”有翅、无翅个体分别标注。
- [ ] 猫栉首蚤 *Ctenocephalides felis*：蚤目、无翅与侧扁身体。共读：“从侧面看看长后腿。”使用显微研究图，不把感染归因于宠物或孩子的过错。
- [ ] 苜蓿跳虫 *Sminthurus viridis*：弹尾类与弹器。共读：“用放大图找找身体下方收起的小叉。”跳跃用连续影像展示。
- [ ] 原尾虫 *Eosentomon transitorium*：原尾类与前足感觉功能。共读：“在显微图里看看前脚怎样向前举起。”头部结构用标注图解释。
- [ ] 双尾虫 *Campodea staphylinus*：双尾类与尾端附肢。共读：“找找身体后面两根长长的尾须。”与蠼螋分开说明。
- [ ] 北方哲水蚤 *Calanus finmarchicus*：桡足类与海洋浮游动物。共读：“在放大图里找找两根长触角。”使用尺度参照，不与昆虫蚤混为一类。
- [ ] 二斑叶螨 *Tetranychus urticae*：螨类与植物上的微小动物。共读：“在显微图里数数成体的脚。”幼体另图注明。
- [ ] 海蜘蛛 *Nymphon gracile*：海蜘蛛类与身体、腿的比例。共读：“找找细小身体周围的长腿。”完整展示附肢，不能按陆生蜘蛛模板画图。
- [ ] 无鞭蝎 *Damon diadema*：无鞭目与感觉型第一对足。共读：“看看最细长的一对脚怎样向前探。”说明它们与行走足的用途差异。
- [ ] 蚰蜒 *Scutigera coleoptrata*：唇足类的长足形态。共读：“看看越靠后的脚是不是更长。”与马陆分别说明。
- [ ] 球马陆 *Glomeris marginata*：倍足类与卷球防御。共读：“对照伸展和卷起的身体，找找脚藏到哪里。”与鼠妇分别注明分类。

## 其他无脊椎动物（30 种）

前 16 项补充软体、刺胞、栉水母、海绵、环节与棘皮动物，后 14 项补充少见类群、显微动物与寄生生活。小颚动物的阶元口径和分类关系须复核，不补造缺失阶元。

- [ ] 新碟贝 *Neopilina galatheae*：单板类，补充帽状壳与软体动物的内部差异。共读：“看看背上的壳，再用腹面示意找找脚。”成对内部结构另附依据。
- [ ] 毛皮贝（中文名待核） *Chaetoderma nitidulum*：尾腔类，补充无典型贝壳、蠕虫形的软体动物。共读：“在微距图里找找身体表面的细小骨针。”不能归为环节动物。
- [ ] 盘鲍 *Haliotis discus*：腹足类，补充开放壳形与附着生活。共读：“沿着壳边找找一排小孔。”
- [ ] 船蛆 *Teredo navalis*：双壳类，补充钻木生活与缩小的壳。共读：“用剖面示意找找木头里的身体。”名称里的“蛆”不表示昆虫幼虫。
- [ ] 地纹芋螺 *Conus geographus*：腹足类，补充捕食性螺与毒液。共读：“看看锥形的壳和表面花纹。”齿舌与捕食用示意，不能根据花纹判断接触安全。
- [ ] 星状海葵 *Nematostella vectensis*：刺胞动物，补充小型海葵与河口底栖生活。共读：“找找口周围一圈细触手。”
- [ ] 耳形十字水母 *Haliclystus auricula*：刺胞动物，补充有柄固着的十字水母类。共读：“找找身体下面连在海藻上的柄。”
- [ ] 诱饵管水母（中文名待核） *Erenna sirena*：刺胞动物，补充群体分工与深海诱捕。共读：“沿着群体找找不同形状的小部分。”群体与个员分别说明。[行为依据：MBARI](https://www.mbari.org/animal/angler-siphonophore/)。
- [ ] 卵形瓜水母 *Beroe ovata*：栉水母，补充无触手的栉水母形态。共读：“找找透明身体上整齐的栉板带。”不能写成刺胞动物或套用触手捕食图。
- [ ] 竖琴海绵 *Chondrocladia lyra*：海绵动物，补充捕食性海绵。共读：“看看竖起的小枝怎样排成一排。”不能把所有海绵都描述为滤食者。[行为依据：MBARI](https://www.mbari.org/news/scientists-discover-extraordinary-new-carnivorous-sponge/)。
- [ ] 湖沼海绵 *Spongilla lacustris*：海绵动物，补充淡水中的固着动物。共读：“在水下枝条上找找附着的海绵。”用放大图说明孔洞，不按绿色外观判断是不是植物。
- [ ] 弗氏食骨虫 *Osedax frankpressi*：环节动物，补充鲸落与细菌共生。共读：“看看骨头上方露出的红色羽状部分。”骨内结构使用剖面示意。[行为依据：MBARI](https://annualreport.mbari.org/2018/story/discovering-animals-never-seen-before)。
- [ ] 螠虫（中文名待核） *Bonellia viridis*：环节动物中的螠虫类，补充雌雄大小差异与长吻。共读：“看看绿色长吻的末端怎样分叉。”不能把小雄虫当成雌虫幼体。
- [ ] 裸体方格星虫 *Sipunculus nudus*：环节动物中的星虫类，补充不显分节的身体与可缩入的吻部。共读：“对照两张图，找找哪一张伸出了前端。”复核分类口径，不直接沿用旧“星虫门”。
- [ ] 蛇发篮海星 *Gorgonocephalus caputmedusae*：棘皮动物中的蛇尾类，补充反复分叉的腕。共读：“沿着一条腕找找分出的细枝。”不能归入海星纲。
- [ ] 游泳海参 *Enypniastes eximia*：棘皮动物，补充海参的游泳方式。共读：“用连续影像看看身体旁的薄膜怎样摆动。”[行为依据：NOAA](https://oceanexplorer.noaa.gov/ocean-fact/what-is-a-headless-chicken-monster/)。
- [ ] 科瓦列夫斯基柱头虫 *Saccoglossus kowalevskii*：半索动物，补充吻、领、躯干的身体结构。共读：“找找前端橡子形的小部分。”与脊索动物分别说明。
- [ ] 头翼箭虫 *Spadella cephaloptera*：毛颚动物，补充透明的捕食性小动物。共读：“在放大图里找找头旁的捕捉刺。”[学名与归属：WoRMS](https://www.marinespecies.org/aphia.php?id=105468&p=taxdetails)。
- [ ] 动吻虫 *Echinoderes dujardinii*：动吻动物，补充海底沉积物中的分节微小身体。共读：“在显微图里沿着身体找找一节节的边界。”
- [ ] 铠甲虫 *Nanaloricus mysticus*：铠甲动物，补充沙粒间生活与外部甲板。共读：“看看放大后的身体外壳。”不能按名字画成甲虫。
- [ ] 鳃曳虫 *Priapulus caudatus*：鳃曳动物，补充可翻出的吻部与钻泥生活。共读：“用连续影像看看前端怎样伸出、缩回。”
- [ ] 鳞皮腹毛虫（中文名待核） *Lepidodermella squamata*：腹毛动物，补充纤毛滑行的淡水微小动物。共读：“看看它怎样沿着表面滑过去。”放大图标注腹面纤毛的位置。
- [ ] 颚口虫（中文名待核） *Gnathostomula paradoxa*：颚胃动物，补充沉积物间隙中的微小蠕虫。共读：“在显微图里看看细长身体怎样弯动。”颚部另配结构示意。
- [ ] 微颚动物 *Limnognathia maerski*：小颚动物类群，补充复杂颚器与淡水显微生活。共读：“先找小身体，再看放大的颚部示意。”制作时核实其分类阶元。
- [ ] 潘多拉共生虫 *Symbion pandora*：环口动物，补充附着在挪威海螯虾口器刚毛上的生活。共读：“从宿主放大到一根刚毛，再找找上面的小动物。”宿主、取食个体与其他生活史阶段分别标注。
- [ ] 垂头海索虫（中文名待核） *Pedicellina cernua*：内肛动物，补充有柄群体与触手冠。共读：“找找细柄顶端的小杯和一圈触手。”与外肛动物分别说明，不能因外形近似混用分类。
- [ ] 南方帚虫 *Phoronis australis*：帚形动物，补充管栖身体与马蹄形触手冠。共读：“看看管口伸出的触手怎样围成弯弯的一圈。”
- [ ] 水生铁线虫 *Gordius aquaticus*：线形动物，补充幼期寄生与成体水中生活。共读：“看看细长身体怎样绕成弯曲的线。”宿主记录需核实到物种，不把线形动物与线虫混为一门。
- [ ] 曼氏血吸虫 *Schistosoma mansoni*：扁形动物，补充吸虫类、宿主转换与寄生生活。共读：“在生活史示意里找找水、螺和成虫各在哪里。”由成人解释，使用非惊吓性示意，不安排接触实验。
- [ ] 蛭态轮虫 *Adineta vaga*：轮虫动物，补充蛭态轮虫的爬行与显微身体。共读：“用显微影像看看它怎样伸长、缩短。”不能按臂尾轮虫模板画成带被甲的身体。

## 制作顺序与资料

建议首批的前五种已完成。后续可继续制作新碟贝、竖琴海绵、科瓦列夫斯基柱头虫、头翼箭虫、微颚动物，补充可见的身体差异与分类空缺；显微、群体和内部结构需要先找到可核对的参考资料再生成图片。上述物种已列在各组中，不重复计数。

选题记录保存本轮 100 种的 GBIF 名称匹配结果与来源入口。它核验候选物种的定位和类群；档案制作仍需研究行为、分布、保护状态、中文名和六张图的内容。

- [GBIF 物种名称匹配 API 说明](https://techdocs.gbif.org/en/openapi/v1/species)：核验候选名称、接受名称与类群，并与现有目录查重。
- [WoRMS 动吻动物数据库](https://www.marinespecies.org/kinorhyncha/index.php)：核对动吻动物与海底间隙生活资料。
- [SICB：铠甲、环口与小颚动物的研究介绍](https://sicb.org/abstracts/an-introduction-to-loricifera-cycliophora-and-gnathometazoa/)：作为三种显微选题的原始研究者介绍；较早文献中的物种数与阶元不能直接当作当前结论。
- [颚胃动物、腹毛动物与扁形动物线粒体基因组研究](https://pubmed.ncbi.nlm.nih.gov/25796325/)：核对 Gnathostomula paradoxa 与 Lepidodermella squamata 的研究对象，亲缘讨论与图谱分类归属分别表达。
- [微生物专题说明](microbes-topic.md)：保留已完成专题的内容、共读方式与卫生资料。
