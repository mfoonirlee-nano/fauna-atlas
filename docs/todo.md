# 待实现的动物

基于现有 111 个物种档案的分类覆盖现状（哺乳纲 30 / 爬行纲 10 / 两栖纲 7 / 鸟纲 13 / 昆虫纲 7 / 蛛形纲 2 / 唇足纲 1 / 倍足纲 1 / 鳃足纲 1 / 刺胞动物门 3〔珊瑚纲 1 / 钵水母纲 1 / 水螅纲 1〕 / 多孔动物门 1〔六放海绵纲 1〕 / 栉水母动物门 1〔触手纲 1〕 / 扁形动物门 1〔被杆体纲 1〕 / 线虫动物门 1〔色矛纲 1〕 / 腕足动物门 1〔舌形贝纲 1〕 / 苔藓动物门 1〔裸唇纲 1〕 / 棘皮动物门 5〔海星纲 1 / 海参纲 1 / 海胆纲 1 / 蛇尾纲 1 / 海百合纲 1〕 / 环节动物门 2〔环带纲 1 / 多毛纲 1〕 / 辐鳍鱼纲 4 / 软骨鱼纲 2 / 肉鳍鱼纲 2 / 海樽纲 1 / 文昌鱼纲 1 / 七鳃鳗纲 1 / 盲鳗纲 1 / 软甲纲 4 / 肢口纲 1 / 软体动物门 6〔头足纲 2 / 腹足纲 1 / 双壳纲 1 / 多板纲 1 / 掘足纲 1〕），
首批原列 30 种，优先补充尚未出现的门、纲与目，并扩充现有薄弱类群，现已完成。
第二批追加 30 种，侧重鲜明的行为、生态关系与身体机制，前两批现剩 29 种。
第三批追加 30 种孩子容易见到或认出的动物，三批现剩 57 种。

## 第二批：奇特行为与身体机制

### 哺乳动物

- [ ] 南方三带犰狳 *Tolypeutes matacus* — 能把头尾严密扣合，将身体闭成近乎完整的甲球
- [ ] 马来鼯猴 *Galeopterus variegatus* — 皮翼目首次收录；颈部、四肢与尾部之间的大面积翼膜承担林冠滑翔
- [ ] 裸鼹鼠 *Heterocephalus glaber* — 单一繁殖雌性与分工成员组成地下群落，是罕见的真社会性哺乳动物

### 鸟类

- [ ] 华丽琴鸟 *Menura novaehollandiae* — 雄鸟能把多种鸟鸣和环境声音编入求偶展示
- [ ] 油鸱 *Steatornis caripensis* — 夜间以果实为食，并用人耳可听见的点击声在黑暗洞穴中回声定位
- [ ] 双角犀鸟 *Buceros bicornis* — 雌鸟封闭树洞巢口，只留下由雄鸟递送食物的窄缝
- [ ] 鲸头鹳 *Balaeniceps rex* — 长时间静止伏击，再用鞋形巨喙突然夹住肺鱼等猎物

### 爬行动物

- [ ] 澳洲棘蜥 *Moloch horridus* — 皮肤表面的微细沟槽能把身体接触到的水引向口部
- [ ] 德州角蜥 *Phrynosoma cornutum* — 遭遇部分捕食者时可从眼周喷血，以气味和味道逼退对方
- [ ] 蛛尾拟角蝰 *Pseudocerastes urarachnoides* — 摆动蜘蛛状尾尖，引诱食虫鸟进入伏击距离

### 两栖动物

- [ ] 壮发蛙 *Trichobatrachus robustus* — 折断趾骨末端，让尖骨刺穿皮肤形成临时防御爪
- [ ] 紫蛙 *Nasikabatrachus sahyadrensis* — 大部分时间在地下活动，只在季风繁殖期短暂现身
- [ ] 达尔文蛙 *Rhinoderma darwinii* — 雄蛙把蝌蚪收入鸣囊，直到幼体变态为小蛙

### 鱼类

- [ ] 大鳍后肛鱼 *Macropinna microstoma* — 透明头罩内的管状眼睛能从朝上转向朝前
- [ ] 叶海龙 *Phycodurus eques* — 叶片状附肢模拟漂动海藻，雄鱼在尾部携带受精卵
- [ ] 电鳗 *Electrophorus electricus* — 用弱放电完成电定位，以强放电捕猎和防御
- [ ] 白斑河鲀 *Torquigener albomaculosus* — 雄鱼在海床筑出直径约 2 米的放射状沙圈作为求偶巢
- [ ] 射水鱼 *Toxotes jaculatrix* — 从水下喷射水柱击落枝叶上的昆虫，并补偿水面折射造成的瞄准偏差

### 尚未收录的门

- [ ] 龙猫栉蚕 *Eoperipatus totoro* — 有爪动物门首次收录；从口侧乳突交叉喷出黏液束缚猎物
- [ ] 拉氏熊虫 *Ramazzottius varieornatus* — 缓步动物门首次收录；脱水时缩成隐生体，复水后可恢复活动
- [ ] 黏丝盘虫 *Trichoplax adhaerens* — 扁盘动物门首次收录；没有神经元、肌肉和器官，仍能协调运动与取食
- [ ] 巨纵沟纽虫 *Lineus longissimus* — 纽形动物门首次收录；能从头部翻出独立长吻捕猎

### 节肢动物门

- [ ] 缩头鱼虱 *Cymothoa exigua* — 吸食使鱼舌萎缩后占据原位，形成近似替代舌的结构
- [ ] 美洲巨鞭蝎 *Mastigoproctus giganteus* — 外形似蝎却没有毒针，受威胁时会喷出带醋酸气味的防御液
- [ ] 蟹奴 *Sacculina carcini* — 成体在蟹体内扩展根状组织，外部只留下承担繁殖的囊体

### 软体动物门

- [ ] 鳞足螺 *Chrysomallon squamiferum* — 足部覆有鳞片，部分种群把硫化铁沉积进外壳和鳞片
- [ ] 幽灵蛸 *Vampyroteuthis infernalis* — 在低氧深海翻起腕间膜包裹身体，并释放发光黏液防御

### 其他无脊椎动物

- [ ] 澳大利亚箱水母 *Chironex fleckeri* — 拥有 24 只眼，其中 8 只带晶状体，能依靠视觉主动避障
- [ ] 博比特虫 *Eunice aphroditois* — 身体埋在海床中，以快速张合的颚伏击游近的猎物

## 第三批：孩子熟悉的常见动物

### 哺乳动物

- [ ] 网纹长颈鹿 *Giraffa reticulata* — 长而灵活的舌头能绕过枝刺，卷下高处的树叶
- [ ] 平原斑马 *Equus quagga* — 每匹斑马都有不同的条纹图案，像自己的身份标记
- [ ] 河马 *Hippopotamus amphibius* — 潜水时会闭合鼻孔和耳朵，每隔几分钟浮出水面换气
- [ ] 猎豹 *Acinonyx jubatus* — 奔跑时用长尾控制转向，爪子像跑鞋钉一样帮助抓地
- [ ] 狐獴 *Suricata suricatta* — 群体觅食时，成员会轮流站上高处放哨并发出警报
- [ ] 环尾狐猴 *Lemur catta* — 雄性把气味擦到尾巴上，再朝对手挥尾展开“臭味大战”
- [ ] 普通浣熊 *Procyon lotor* — 灵敏的前爪能在浅水和缝隙中摸索食物

### 鸟类

- [ ] 大红鹳 *Phoenicopterus roseus* — 幼鸟出生时呈灰白色，食物中的类胡萝卜素会让羽毛逐渐变粉
- [ ] 虎皮鹦鹉 *Melopsittacus undulatus* — 善于学习声音，部分个体还能模仿人说话
- [ ] 托哥巨嘴鸟 *Ramphastos toco* — 巨喙内部由轻巧的骨质网架支撑，还能帮助身体散热
- [ ] 普通翠鸟 *Alcedo atthis* — 从枝头俯冲入水捕鱼，瞬膜会像护目镜一样保护眼睛
- [ ] 鸳鸯 *Aix galericulata* — 在树洞中筑巢，刚孵化的雏鸟会从高处跳到地面
- [ ] 家燕 *Hirundo rustica* — 衔来泥团筑成杯状巢，并在飞行中捕捉昆虫

### 爬行动物

- [ ] 绿鬣蜥 *Iguana iguana* — 头顶的“顶眼”能感受明暗变化，帮助它发现来自上方的危险
- [ ] 中部鬃狮蜥 *Pogona vitticeps* — 紧张或展示时会撑开并变黑喉部的“胡子”
- [ ] 高冠变色龙 *Chamaeleo calyptratus* — 两只眼睛能分头观察，发现昆虫后再用长舌捕捉

### 两栖动物

- [ ] 东方铃蟾 *Bombina orientalis* — 遇到威胁时会拱起身体，露出橙红色腹部警告捕食者

### 鱼类

- [ ] 眼斑双锯鱼（小丑鱼） *Amphiprion ocellaris* — 保护性黏液帮助它穿梭在海葵带刺的触手之间
- [ ] 金鱼 *Carassius auratus* — 没有真正的胃，会用长在咽喉部位的咽齿碾碎食物
- [ ] 暹罗斗鱼 *Betta splendens* — 鳃上方的迷鳃器让它能到水面吞咽空气
- [ ] 大白鲨 *Carcharodon carcharias* — 后排牙齿会向前补位，替换捕猎时脱落的牙齿

### 无脊椎动物

- [ ] 东方蜜蜂 *Apis cerana* — 工蜂用摆尾舞告诉同伴花朵的方向和距离
- [ ] 双斑蟋蟀 *Gryllus bimaculatus* — 雄虫摩擦前翅鸣叫，听声音的“耳朵”却长在前腿上
- [ ] 独角仙 *Trypoxylus dichotomus* — 雄虫用分叉长角角力，把争夺树汁的对手掀开
- [ ] 枯叶蛱蝶 *Kallima inachus* — 合拢翅膀后，翅脉和翅尖组成一片带叶柄的枯叶
- [ ] 红胸水萤 *Aquatica lateralis* — 成虫在夜里闪光，幼虫生活在水中
- [ ] 寻常球鼠妇（西瓜虫） *Armadillidium vulgare* — 它是陆生甲壳动物，受惊后会把身体卷成圆球
- [ ] 散大蜗牛 *Cornu aspersum* — 四根触角都能缩回头部，眼睛长在较长一对的末端
