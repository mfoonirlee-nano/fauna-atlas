## 第三批：孩子熟悉的常见动物

### 哺乳动物

- [ ] 河马 *Hippopotamus amphibius* — 潜水时会闭合鼻孔和耳朵，每隔几分钟浮出水面换气
- [ ] 猎豹 *Acinonyx jubatus* — 奔跑时用长尾控制转向，爪子像跑鞋钉一样帮助抓地
- [ ] 环尾狐猴 *Lemur catta* — 雄性把气味擦到尾巴上，再朝对手挥尾展开“臭味大战”

### 鸟类

- [ ] 大红鹳 *Phoenicopterus roseus* — 幼鸟出生时呈灰白色，食物中的类胡萝卜素会让羽毛逐渐变粉
- [ ] 虎皮鹦鹉 *Melopsittacus undulatus* — 善于学习声音，部分个体还能模仿人说话
- [ ] 托哥巨嘴鸟 *Ramphastos toco* — 巨喙内部由轻巧的骨质网架支撑，还能帮助身体散热
- [ ] 普通翠鸟 *Alcedo atthis* — 从枝头俯冲入水捕鱼，瞬膜会像护目镜一样保护眼睛
- [ ] 鸳鸯 *Aix galericulata* — 在树洞中筑巢，刚孵化的雏鸟会从高处跳到地面
- [ ] 家燕 *Hirundo rustica* — 衔来泥团筑成杯状巢，并在飞行中捕捉昆虫

### 爬行动物

- [ ] 绿鬣蜥 *Iguana iguana* — 头顶的“顶眼”能感受明暗变化，帮助它发现来自上方的危险
- [ ] 中部鬃狮蜥 *Pogona vitticeps* — 紧张或展示时会撑开并变黑喉部的“胡子”
- [ ] 高冠变色龙 *Chamaeleo calyptratus* — 两只眼睛能分头观察，发现昆虫后再用长舌捕捉

### 两栖动物

- [ ] 东方铃蟾 *Bombina orientalis* — 遇到威胁时会拱起身体，露出橙红色腹部警告捕食者

### 鱼类

- [ ] 金鱼 *Carassius auratus* — 没有真正的胃，会用长在咽喉部位的咽齿碾碎食物
- [ ] 暹罗斗鱼 *Betta splendens* — 鳃上方的迷鳃器让它能到水面吞咽空气
- [ ] 大白鲨 *Carcharodon carcharias* — 后排牙齿会向前补位，替换捕猎时脱落的牙齿

### 无脊椎动物

- [ ] 东方蜜蜂 *Apis cerana* — 工蜂用摆尾舞告诉同伴花朵的方向和距离
- [ ] 双斑蟋蟀 *Gryllus bimaculatus* — 雄虫摩擦前翅鸣叫，听声音的“耳朵”却长在前腿上
- [ ] 独角仙 *Trypoxylus dichotomus* — 雄虫用分叉长角角力，把争夺树汁的对手掀开
- [ ] 枯叶蛱蝶 *Kallima inachus* — 合拢翅膀后，翅脉和翅尖组成一片带叶柄的枯叶
- [ ] 红胸水萤 *Aquatica lateralis* — 成虫在夜里闪光，幼虫生活在水中
