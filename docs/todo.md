# 待实现的动物

基于现有 30 个物种档案的分类覆盖现状（哺乳纲 12 / 爬行纲 5 / 两栖纲 4 / 鸟纲 3 / 昆虫纲 2 / 刺胞动物门 2 / 软骨鱼纲 1 / 软甲纲 1），
优先补充尚未出现的门与纲，并扩充薄弱类群。

## 填补分类图谱空缺

- [ ] 中华鲟 *Acipenser sinensis* — 辐鳍鱼纲尚无任何物种；国家一级保护动物
- [ ] 腔棘鱼 *Latimeria chalumnae* — 肉鳍鱼纲代表，"活化石"
- [ ] 普通章鱼 *Octopus vulgaris* — 软体动物门·头足纲
- [ ] 鹦鹉螺 *Nautilus pompilius* — 软体动物门·头足纲原始类群
- [ ] 巨砗磲 *Tridacna gigas* — 软体动物门·双壳纲，现存最大双壳类
- [ ] 棘冠海星 *Acanthaster planci* — 棘皮动物门首次收录，珊瑚礁生态关键种
- [ ] 巨人捕鸟蛛 *Theraphosa blondi* — 蛛形纲首次收录，最重蜘蛛

## 扩充鸟纲（当前仅 3 种）

- [ ] 朱鹮 *Nipponia nippon* — 从极危到复壮的保护成功典范
- [ ] 丹顶鹤 *Grus japonensis* — 东亚湿地旗舰物种
- [ ] 金雕 *Aquila chrysaetos* — 猛禽代表，分布最广的雕类
- [ ] 非洲鸵鸟 *Struthio camelus* — 古颚下纲代表，现存最大鸟类

## 补充缺失的哺乳动物目

- [ ] 中华穿山甲 *Manis pentadactyla* — 鳞甲目整目缺失；极度濒危
- [ ] 儒艮 *Dugong dugon* — 海牛目整目缺失；中国海域已功能性灭绝
- [ ] 白犀 *Ceratotherium simum* — 奇蹄目整目缺失
- [ ] 褐喉树懒 *Bradypus variegatus* — 异关节总目（披毛目）缺失
- [ ] 欧亚河狸 *Castor fiber* — 啮齿目（最大哺乳动物目）缺失，生态系统工程师
- [ ] 中华菊头蝠 *Rhinolophus sinicus* — 翼手目（第二大目）缺失
