# 待实现的动物

基于现有 60 个物种档案的分类覆盖现状（哺乳纲 26 / 爬行纲 8 / 两栖纲 4 / 鸟纲 11 / 昆虫纲 2 / 刺胞动物门 2 / 辐鳍鱼纲 2 / 软骨鱼纲 1 / 肉鳍鱼纲 1 / 文昌鱼纲 1 / 七鳃鳗纲 1 / 软甲纲 1），
优先补充尚未出现的门与纲，并扩充薄弱类群，剩余 18 种。

## 鱼类与演化关键物种

- [ ] 大西洋蓝鳍金枪鱼 *Thunnus thynnus* — 远洋巡游鱼类代表
- [ ] 大弹涂鱼 *Boleophthalmus pectinirostris* — 滩涂鱼类，与招潮蟹同域共生景观

## 无脊椎动物

### 节肢动物门

- [ ] 中华鲎 *Tachypleus tridentatus* — 鲎纲（肢口纲）现生代表；蓝色血液，中国东南沿海，濒危
- [ ] 巨人捕鸟蛛 *Theraphosa blondi* — 蛛形纲首次收录，最重蜘蛛
- [ ] 中华大刀螳 *Tenodera sinensis* — 螳螂目，丰富昆虫多样性
- [ ] 七星瓢虫 *Coccinella septempunctata* — 鞘翅目（物种数最多的昆虫目）
- [ ] 皇帝蜻蜓 *Anax imperator* — 蜻蜓目，古老有翅昆虫代表
- [ ] 家蚕 *Bombyx mori* — 蚕蛾科，与帝王蝶同目对照；中国驯化的物种
- [ ] 南极磷虾 *Euphausia superba* — 磷虾目，生物量最大的野生动物，南大洋关键种
- [ ] 椰子蟹 *Birgus latro* — 现存最大陆生节肢动物（与招潮蟹同为十足目）

### 软体动物门

- [ ] 鹦鹉螺 *Nautilus pompilius* — 头足纲原始类群
- [ ] 普通章鱼 *Octopus vulgaris* — 头足纲
- [ ] 大西洋海神海蛞蝓 *Glaucus atlanticus* — 腹足纲裸鳃类
- [ ] 巨砗磲 *Tridacna gigas* — 双壳纲，现存最大双壳类

### 其他门类

- [ ] 僧帽水母 *Physalia physalis* — 刺胞动物门·水螅纲管水母，群体生物（与单体海月水母对照）
- [ ] 棘冠海星 *Acanthaster planci* — 棘皮动物门首次收录，珊瑚礁生态关键种
- [ ] 仿刺参 *Apostichopus japonicus* — 棘皮动物门·海参纲，棘皮第二纲
- [ ] 巨蚯蚓 *Megascolides australis* — 环节动物门首次收录，最长蚯蚓之一
