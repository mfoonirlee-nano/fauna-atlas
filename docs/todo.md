# 待实现的动物

基于现有 40 个物种档案的分类覆盖现状（哺乳纲 22 / 爬行纲 4 / 两栖纲 3 / 鸟纲 3 / 昆虫纲 2 / 刺胞动物门 2 / 辐鳍鱼纲 1 / 软骨鱼纲 1 / 肉鳍鱼纲 1 / 软甲纲 1），
优先补充尚未出现的门与纲，并扩充薄弱类群，剩余 38 种。

## 哺乳动物

- [ ] 藏羚羊 *Pantholops hodgsonii* — 牛科，青藏高原，反盗猎保护成功案例
- [ ] 亚洲象 *Elephas maximus* — 与非洲草原象同科不同属；云南种群北迁引发广泛关注
- [ ] 针鼹 *Tachyglossus aculeatus* — 单孔目针鼹科，与鸭嘴兽同目对照
- [ ] 长江江豚 *Neophocaena asiaeorientalis* — 鼠海豚科（与海豚科宽吻海豚对照）；"微笑天使"，国家一级

## 鸟类

- [ ] 朱鹮 *Nipponia nippon* — 从极危到复壮的保护成功典范
- [ ] 丹顶鹤 *Grus japonensis* — 东亚湿地旗舰物种
- [ ] 金雕 *Aquila chrysaetos* — 猛禽代表，分布最广的雕类
- [ ] 游隼 *Falco peregrinus* — 俯冲速度最快的动物，隼形目
- [ ] 雪鸮 *Bubo scandiacus* — 鸮形目（夜行猛禽）代表
- [ ] 绿孔雀 *Pavo muticus* — 鸡形目，中国仅存于云南，濒危
- [ ] 北极燕鸥 *Sterna paradisaea* — 已知迁徙距离最长的动物
- [ ] 非洲鸵鸟 *Struthio camelus* — 古颚下纲代表，现存最大鸟类

## 爬行动物

- [ ] 喙头蜥 *Sphenodon punctatus* — 喙头目仅存的唯一现生物种
- [ ] 尼罗鳄 *Crocodylus niloticus* — 与恒河鳄形成鳄目内科的对照
- [ ] 棱皮龟 *Dermochelys coriacea* — 棱皮龟科，与绿海龟（海龟科）对照，最大海龟
- [ ] 海鬣蜥 *Amblyrhynchus cristatus* — 唯一适应海洋生活的蜥蜴

## 两栖动物

- [ ] 非洲巨蛙 *Conraua goliath* — 现存最大蛙类

## 鱼类与演化关键物种

- [ ] 文昌鱼 *Branchiostoma belcheri* — 头索动物，无脊椎到脊椎的演化关键，中国沿海有产
- [ ] 海七鳃鳗 *Petromyzon marinus* — 圆口纲（无颌类）代表
- [ ] 巨骨舌鱼 *Arapaima gigas* — 亚马逊巨型淡水鱼，最大纯淡水鱼之一
- [ ] 大西洋蓝鳍金枪鱼 *Thunnus thynnus* — 远洋巡游鱼类代表
- [ ] 大弹涂鱼 *Boleophthalmus pectinirostris* — 滩涂鱼类，与招潮蟹同域共生景观

## 无脊椎动物

### 节肢动物门

- [ ] 中华鲎 *Tachypleus tridentatus* — 鲎纲（肢口纲）现生代表；蓝色血液，中国东南沿海，濒危
- [ ] 巨人捕鸟蛛 *Theraphosa blondi* — 蛛形纲首次收录，最重蜘蛛
- [ ] 中华大刀螳 *Tenodera sinensis* — 螳螂目，丰富昆虫多样性
- [ ] 七星瓢虫 *Coccinella septempunctata* — 鞘翅目（物种数最多的昆虫目）
- [ ] 皇帝蜻蜓 *Anax imperator* — 蜻蜓目，古老有翅昆虫代表
- [ ] 家蚕 *Bombyx mori* — 蚕蛾科，与帝王蝶同目对照；中国驯化的物种
- [ ] 南极磷虾 *Euphausia superba* — 磷虾目，生物量最大的野生动物，南大洋关键种
- [ ] 椰子蟹 *Birgus latro* — 现存最大陆生节肢动物（与招潮蟹同为十足目）

### 软体动物门

- [ ] 鹦鹉螺 *Nautilus pompilius* — 头足纲原始类群
- [ ] 普通章鱼 *Octopus vulgaris* — 头足纲
- [ ] 大西洋海神海蛞蝓 *Glaucus atlanticus* — 腹足纲裸鳃类
- [ ] 巨砗磲 *Tridacna gigas* — 双壳纲，现存最大双壳类

### 其他门类

- [ ] 僧帽水母 *Physalia physalis* — 刺胞动物门·水螅纲管水母，群体生物（与单体海月水母对照）
- [ ] 棘冠海星 *Acanthaster planci* — 棘皮动物门首次收录，珊瑚礁生态关键种
- [ ] 仿刺参 *Apostichopus japonicus* — 棘皮动物门·海参纲，棘皮第二纲
- [ ] 巨蚯蚓 *Megascolides australis* — 环节动物门首次收录，最长蚯蚓之一
