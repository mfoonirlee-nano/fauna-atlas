范围：项目全部动物物种档案、相关配图、探索入口、数据模型与页面展示。

本文记录全量重构方案；第一阶段进展见[全量盘点说明](learning-refactor/README.md)，第二阶段首批 5 种见[内容样板](learning-refactor/samples/README.md)。本轮按用户要求先做 5 种，五种档案及其详情页已接入儿童讲解，其他物种尚未迁移；2026-11-11 已将代码提交 `513c107b` 部署到 Cloudflare。文中的年龄、样板数量和批次规模均为建议，需要在样板阶段验证。

## 1. 产品目标与现状

将项目调整为面向儿童、从观察动物到理解生命与保护的动物百科。每份物种档案按以下顺序组织：

**长什么样 → 身体有什么本领 → 住在哪里 → 吃什么、怎样找食物 → 怎样生活和长大 → 在自然中有什么作用 → 现在过得怎么样。**

本计划依据项目说明、物种类型、详情页实现，以及大熊猫、真猛犸象等抽样档案制定，尚未完成全部档案的事实与质量审核。

项目已有分类、分布、栖息地、食性、活动习性、保护状态和资料来源，并支持档案按需加载。保留这些基础，重点调整学习顺序、补齐内容缺口、建立全量质量标准。

当前详情页首屏突出保护等级和种群趋势，身体特征与生活习性主要在后续长文中呈现。新版先帮助儿童认识动物，再解释其生活需要，最后深入介绍保护与灭绝。

## 2. 读者与阅读层次

以 6—12 岁儿童为主要读者，兼顾低龄亲子共读。这是工作假设，需结合实际用户和试读结果调整。

同一份档案提供分层内容，避免多套版本重复维护导致事实不一致。

| 阅读层次 | 学习目标 | 呈现方式 |
| --- | --- | --- |
| 先认识 | 名字、外形、住处、主要食物 | 图片、短句、少量关键事实 |
| 再理解 | 身体结构的用途，觅食和生活方式 | 分段讲解、结构图、行为图 |
| 深入探索 | 生态关系、濒危原因、灭绝证据 | 可展开内容、对比、时间线 |
| 资料查阅 | 来源、时效与不确定性 | 资料链接、评估年份、证据说明 |

编辑要求：

- 专业词首次出现时就地解释，例如“夜行性：主要在夜间活动”。
- 一段围绕一个问题，减少长定语和连续堆叠的数据。
- 用可观察的现象引出解释，不凭空赋予动物人的情感、道德或目的。
- 区分物种普遍特征与年龄、性别、季节、地区造成的差异。
- 数据保留单位、测量口径和适用范围，不把极值写成所有个体的常态。

## 3. 全量档案的内容骨架

统一问题与内容要求，允许不同动物采用不同的回答方式。鸟类、昆虫、水母和古生物不能机械套用哺乳动物模板。

| 顺序 | 栏目 | 必须回答的问题 |
| --- | --- | --- |
| 1 | 认识它 | 叫什么？属于哪类动物？最容易认出的特征是什么？ |
| 2 | 看看它的身体 | 重要身体部分是什么？怎样帮助它生活？ |
| 3 | 它的家在哪里 | 分布在哪些地区？生活在什么环境？需要什么条件？ |
| 4 | 它的食物从哪里来 | 吃什么？怎样搜寻、捕获或取得食物？怎样进食？ |
| 5 | 它怎样度过一天 | 什么时候活动？独居还是群居？怎样移动、休息和交流？ |
| 6 | 它怎样长大 | 怎样繁殖？幼体与成体有何不同？是否有亲代照顾？ |
| 7 | 它和其他生命 | 与捕食者、猎物、植物或其他动物有什么联系？ |
| 8 | 它现在怎么样 | 仍然生存、受到威胁，还是已灭绝？依据是什么？ |
| 9 | 再观察一下 | 一个观察任务、一两个理解问题，以及相关动物 |
| 10 | 资料来源 | 主要事实与保护结论分别来自哪里？ |

重点补强：

1. **身体构造**：连接“结构是什么—能做什么—如何适应环境”，覆盖外形、运动、感官、取食，以及适合该动物的基础内部结构。
2. **觅食过程**：分开记录食物与获取方式，解释搜寻、捕捉、过滤、啃咬等行为。
3. **生活与成长**：分清活动节律、社会行为、繁殖和幼体成长，减少栏目重复。

每个基础问题都应有可靠内容，或明确说明资料不足、不适用及其原因。缺乏证据时不编写完整的“一天”，也不为填满模板推测动物行为。

## 4. 详情页阅读顺序

1. **首屏认识动物**：中文名、清晰配图、一句话介绍，以及体型、住处和食物等少量基础信息。
2. **身体观察**：先看整体，再指出两三个关键结构，解释用途。
3. **日常生活**：依次展开栖息地、觅食、活动、成长。
4. **生态关系**：介绍其参与食物网及与其他生命的联系。
5. **保护或灭绝**：在理解动物生活需要后，解释环境变化及其后果。
6. **观察与查阅**：提供观察问题、相关动物和资料来源。

已灭绝动物在首屏清楚标明“已灭绝”，详细年代、原因和证据放入专门章节。

长页面提供简短目录并保留阅读位置。核心信息默认展示，学名、完整分类路径、详细数据和扩展资料可展开查看。结构图和其他交互须兼顾触屏、键盘操作及文字替代说明，不能只靠悬停或颜色表达信息。

## 5. 现生动物与灭绝动物的分支

| 类型 | 讲解重点 |
| --- | --- |
| 现生动物 | 当前分布、野外生活、保护评估、威胁和已开展的保护工作 |
| 近代灭绝动物 | 历史分布、最后记录、灭绝过程及证据 |
| 古生物 | 生活年代、古环境、化石证据、复原依据与不确定性 |

保护章节按“它需要什么 → 哪些条件改变了 → 带来什么影响 → 人们怎样帮助”组织，避免只罗列威胁名称。

沿用项目既有科学边界：

- 分别解释易危、濒危、极危，不统一替换成“濒危”。
- 无危不代表永远安全；数据缺乏不代表已经确认安全或危险。
- “保护评估待核实”是编辑状态，与正式评估类别分开。
- 全球评估、中国保护名录和地方种群情况分别标明范围。
- 灭绝年代与保护评估年份分别记录。
- 古生物的形态和行为区分直接证据、研究推断与仍未知的部分。
- 儿童行动建议采用不投喂、不捕捉、减少干扰、在成人陪同下观察等具体行为，避免把物种保护责任转嫁给儿童。

相关约束见 [CONTEXT.md](../CONTEXT.md)、[灭绝证据 ADR](../docs/adr/0003-extinction-evidence.md)和[待核实评估与待修复配图 ADR](../docs/adr/0004-unverified-evidence-and-pending-media.md)。

## 6. 首页、搜索与探索入口

| 入口 | 示例 | 用途 |
| --- | --- | --- |
| 今天认识一种动物 | 一种动物、一幅图、一个问题 | 降低首次阅读门槛 |
| 按生活环境探索 | 森林、草原、淡水、海洋 | 从熟悉场景进入 |
| 按身体与本领探索 | 有壳、善于游泳、会伪装 | 从可观察特征进入 |
| 按生活方式探索 | 夜间活动、迁徙、群居 | 比较不同动物 |
| 探索远古生命 | 古生物、近代灭绝动物 | 建立时间概念 |
| 分类图谱与地图 | 现有功能 | 支持进一步查阅 |

兴趣主题与正式分类单元分开。“会飞的动物”属于学习主题，不作为分类单元；分类图谱继续只表达分类归属，不表达演化时间或祖先关系。

搜索保留名称、别名等能力，再逐步增加食物、生活环境、身体特征等条件。地图继续说明代表点不等于完整分布范围，灭绝动物的历史范围不得呈现为当前活体分布。

微生物专题继续独立组织，不进入动物物种档案或动物分类图谱。本轮全量迁移范围为动物内容。

## 7. 全量盘点与迁移方式

先生成全量清单，为每份物种档案记录：

- 稳定 ID、slug、名称、所属类群及现生或灭绝情况。
- 身份与分类是否准确。
- 身体构造、觅食、活动、成长、生态关系等栏目是否完整。
- 保护或灭绝结论是否有证据，相关日期是否需复核。
- 是否存在过难、重复、含糊或过度拟人的表达。
- 配图是否准确，是否支持正文观察。
- 待整理、待补资料、待审核、待修图或可发布等工作状态。
- 未解决问题、处理人和复核记录。

| 盘点结果 | 处理方式 |
| --- | --- |
| 资料较完整 | 重排阅读顺序、改写儿童表达、补结构化字段 |
| 内容缺口较大 | 先补身体结构、觅食、成长等资料，再改写 |
| 事实或配图有疑点 | 先核实证据并修正，再纳入新版 |

先制作 12—20 种样板，覆盖哺乳动物、鸟类、爬行动物、两栖动物、鱼类、节肢动物、软体动物、其他无脊椎动物，以及近代灭绝动物和古生物。选择结构和生活方式差异大的动物，验证模板对不同类群的适用性。

全量迁移先按每批 20—30 种试行，并结合类群与资料质量安排。前两批完成后，用资料补充、改写、图片修正和审核的实际耗时估算剩余工期。盘点完成前不承诺总周期。

既有新增动物制作任务仍参见 [docs/todo.md](../docs/todo.md)。样板阶段应明确新增档案如何遵循新版标准，避免旧模板继续扩大迁移量。

## 8. 数据模型与代码调整

在现有 `Species` 基础上扩展，保留档案按需加载。将科学事实、儿童讲解、学习活动分别组织，具体字段方案在样板阶段确定。

| 信息层 | 内容 |
| --- | --- |
| 科学事实 | 分类、体型、分布、食物、评估、年代和来源 |
| 儿童讲解 | 简短介绍、结构功能解释、分层段落和术语解释 |
| 学习活动 | 图片观察点、比较问题、小测验和延伸阅读 |

实施任务：

- [ ] 为身体结构、觅食方式、生活节律、成长和生态关系设计明确字段。
- [ ] 设计关键事实与来源的关联，记录适用范围、证据确定程度和审核时间。
- [ ] 分开建模灭绝年代、末次记录和推测原因。
- [ ] 保留旧 `storySections` 作为迁移内容来源，逐份转换后决定如何收敛。
- [ ] 按阅读章节拆分详情页组件。
- [ ] 增加迁移版本和完成状态，避免把未补齐档案标记为新版完成。
- [ ] 验证新旧档案兼容、目录摘要字段和独立档案加载。
- [ ] 依据最终设计更新领域文档及需要的 ADR。

自动化用于整理字段、发现缺项和检查冲突。物种事实、结构功能及古生物推断仍需资料核对；不能仅凭字段存在判断内容合格。

## 9. 配图整理与审核

先按教学用途盘点现有图片，再补缺口，不要求每种动物机械配齐同样数量的新图。新增或替换素材仍遵循[项目物种图片与封面规则](../src/assets/source/README.md#species-image-set-rule)。如需调整既有图片数量要求，另行明确修改规则。

| 用途 | 需要帮助儿童观察的内容 |
| --- | --- |
| 整体外形图 | 动物主要形态 |
| 结构观察图 | 关键部位、名称与功能 |
| 觅食或行为图 | 动物怎样生活 |
| 栖息地图 | 动物与环境的关系 |
| 成长图 | 幼体、成体的重要差异 |
| 证据或复原图 | 古生物证据与复原依据 |

结构图重点审核部位、比例和标注。AI 生成配图保留明确说明；真实摄影、示意图和古生物复原分别标识，不能凭逼真程度认定科学准确。待修复素材继续不在前台展示。

## 10. 阶段安排与交付物

| 阶段 | 主要工作 | 交付物与完成条件 |
| --- | --- | --- |
| 1. 全量盘点 | 扫描全部档案、图片和来源 | 每种动物都有缺项、风险及处理状态 |
| 2. 标准与样板 | 确定阅读层次，制作代表性档案 | 内容模板、编辑规范、12—20 种样板通过审核 |
| 3. 页面与模型 | 扩展字段，改造详情页与探索入口 | 样板完整呈现，新旧档案均可正常读取 |
| 4. 分批迁移 | 按类群和质量处理全量档案 | 每批完成资料核对、文案审核、配图审核和技术验证 |
| 5. 全量验收 | 检查遗漏、冲突、加载及易用性 | 全部档案达到标准，未解决问题有明确记录 |
| 6. 持续维护 | 复核评估、来源及反馈 | 建立更新规则和负责人 |

阶段 2 完成后再扩大迁移范围。阶段 4 根据试运行产能更新批次安排；事实或图片问题未解决的档案不得为追求批次完成而通过审核。

## 11. 验收标准

### 内容与科学性

- [ ] 全部动物都在盘点清单中，迁移数量与实际目录一致。
- [ ] 基础栏目有可靠内容，或明确记录资料不足、不适用及原因。
- [ ] 关键事实可追溯，重要数据保留单位、口径和适用范围。
- [ ] 保护评估、编辑待核实状态、灭绝证据和相关年份不混淆。
- [ ] 古生物复原区分证据、推断和未知。
- [ ] 配图通过生物学核验，待修复素材未进入前台。
- [ ] 各批次保留审核与未解决问题记录。

### 儿童理解与使用

- [ ] 安排小范围亲子试读，观察儿童能否找到主要食物和住处。
- [ ] 观察儿童能否解释一种身体结构的用途。
- [ ] 对适用档案，观察儿童能否说出主要生存问题。
- [ ] 根据试读记录修改难词、内容顺序和交互，不将未经验证的设计假设写成效果结论。
- [ ] 核查移动端阅读、键盘操作、图像替代文字和不依赖颜色的信息表达。

### 技术验证

- [ ] 运行类型检查、构建及与改动相关的测试。
- [ ] 验证搜索筛选、分类一致性、档案按需加载与新旧数据兼容。
- [ ] 验证图片路径、子路径资源访问和现有构建体积预算。
- [ ] 按仓库要求选择验证方式，不使用 GUI 或无头浏览器进行验证。

人工试读与技术验证分别记录；测试通过不能替代科学审核或儿童理解验证。
