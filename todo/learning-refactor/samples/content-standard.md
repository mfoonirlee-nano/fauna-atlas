# 五种动物样板的内容标准

日期：2026-11-11。状态：首批编辑稿，待专业复核与亲子试读。

本轮按用户要求制作 5 种样板。沿用 6—12 岁为主要读者、兼顾亲子共读的工作假设；尚未通过试读证明适龄。正文先在本目录审阅，暂不接入前台，不修改正式物种数据或生成素材。

## 阅读顺序

| 栏目 | 必须回答的问题 | 编辑要求 |
| --- | --- | --- |
| 认识它 | 名字、所属动物类群、最易辨认的特征 | 用准确中文名，学名放资料区；不能用“可爱”等评价代替特征 |
| 看看身体 | 关键部位是什么，怎样帮助生活 | 写清“部位—作用”，外部形态与内部结构分开；不能要求从外观图看到隐藏器官 |
| 家在哪里 | 分布和栖息环境各是什么 | 地区与环境分开，历史分布明确使用过去时 |
| 怎样找食物 | 吃什么、如何取得和处理食物 | 不把食谱当作觅食解释，不把一种观察当作固定行为 |
| 怎样生活 | 活动、移动、休息或交流 | 不编造完整日程；地域、季节、生命阶段差异就地说明 |
| 怎样长大 | 繁殖、幼体与成体变化、照顾方式 | 不统一套用“爸爸妈妈共同养育”，不将实验天数写成野外规律 |
| 和其他生命 | 可追溯的食物关系或生态联系 | 不为每种动物强行赋予未经证实的“生态贡献” |
| 生存处境 | 现生、威胁或灭绝，原因及依据 | 解释等级与评估范围；评估年份不是访问年份或灭绝年代 |
| 再观察一下 | 图片观察和理解问题 | 图片能回答的问题与需要阅读的问题分开；答案说明理由 |
| 资料 | 关键事实来自哪里 | 正文引用对应来源编号，保留日期、范围和不确定性 |

## 两层内容

每份样板开头提供一句话认识动物。各栏目默认讲清基本事实，只在需要因果、范围或证据区别时增加“再想一想”段落。当前稿件中的编辑资料区和来源对应表供维护者审阅，不要求儿童逐项阅读。

不机械规定每段字数，也不为了填满栏目补入未经核实的内容。适龄性要通过实际共读检查。

## 语言与术语

- 专业词首次出现时就地解释，例如“臼齿：嘴里用来磨碎食物的后部牙齿”。
- 先讲看得见的部位和行为，再解释原理；需要新示意图的内容仍能独立读懂。
- 用“常常”“在某些地区”“研究推断”等词保留条件，不把概率变成必然。
- 不用“聪明所以……”“为了帮助人类……”等缺乏证据的拟人归因。
- 不用猎奇方式讲捕食、死亡和灭绝；儿童行动建议以观察、不干扰为主。
- 数值必须有来源、单位、适用范围；不强行给资料不足的动物补齐体重、寿命或速度。
- 已有“发现与命名”等扩展材料留在正式档案，本轮不删除；后续页面可作为延伸阅读组织。

## 证据与保护状态

来源 HTTP 200 只证明请求成功。必须阅读相关正文，记录支持的事实和限制；网站导航、搜索摘要与打不开的文献不能替代正文核对。

IUCN 评估区分物种、亚种和地理范围。无危不表示任何地区都安全，易危和濒危分别解释。正式数据中的 UNVERIFIED 保持独立，不借用 NE 或 DD 表示编辑未完成。

普通章鱼的旧保护评估使用较宽种界，不能直接当成现行狭义种的全新评估。真猛犸象使用历史和化石依据，不填 IUCN 评估年份；其生活方式要区分遗存证据与推断。

来源链接及核对结果见 [sources.json](sources.json)，逐种进展见 [sample-status.json](sample-status.json)。访问失败的候选来源单独记录，不计为已阅读全文。

## 配图与观察题

本轮对现有 30 张图片做教学用途初筛，保持原图、裁切与发布状态。生成图标识和古生物复原说明继续保留。初筛不等于新增生物学验收。

每份样板指定一张现有观察图及能看见的特征。看不清的卵、牙齿、伪拇指、吸盘细节等，不设计成“请在图中找到”的题目。

新增示意图先登记在 [media-todo.md](media-todo.md)。制作前必须确认参考、标注与审核条件；本轮不生成，也不把候选任务自动视为必须制作。
