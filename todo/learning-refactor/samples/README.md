## 五种动物

| 样板 | 选择理由 | 需要验证的内容区别 |
| --- | --- | --- |
| [大熊猫](giant-panda.md) | 熟悉的哺乳动物，便于从外形进入结构功能 | 伪拇指与真手指、食肉目与实际食谱、幼崽照顾 |
| [帝企鹅](emperor-penguin.md) | 鸟类，同时依赖海水和海冰 | 翅膀与潜水、脚背孵卵、幼鸟羽毛、2026 年濒危更新 |
| [帝王蝶](monarch-butterfly.md) | 昆虫的不同生命阶段差异明显 | 完全变态、不同食物、物种与迁徙亚种评估范围 |
| [普通章鱼](common-octopus.md) | 柔软身体，生活方式与前三种不同 | 腕与吸盘、伪装、浮游幼体、旧评估与现行种界 |
| [真猛犸象](woolly-mammoth.md) | 已灭绝动物，能验证证据和未知的表达 | 臼齿与象牙、幼体遗存、历史分布、灭绝与复原限制 |

五种样板不能覆盖所有动物类群。后续是否扩展到鱼类、两栖动物等，应根据本批审阅结果安排，不把本轮数量当作全量模板已经验证的依据。

## 这次怎样核对

1. 读取正式档案及现有资料来源，保留身份、分类、保护记录和素材状态。
2. 访问并阅读相关正文；保护等级优先对照 IUCN，生态与形态参考政府、动物园、博物馆和研究文献。
3. 用短句重组儿童讲解，逐栏目标出来源。缺少证据的内容保留缺口；未依据搜索结果直接补写日常行为。
4. 对五种动物共 30 张现有图片制作临时联系表，在本地查看并记录教学用途。临时联系表只用于检查，未加入产品素材或仓库。
5. 检查五份稿件的栏目、引用、稳定 ID、来源摘录及本地链接，确认没有修改正式数据或媒体文件。
