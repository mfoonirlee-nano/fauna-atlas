## 局限

这些是 AI 科学重建，不是真实显微照片，也不证明精确的物种或菌株身份。配色、纹理、透明度、胞内细节及模糊背景属于说明性重建；不按比例，不能据此推断真实尺寸、生态环境或致病性。

贾第鞭毛虫为滋养体，未展示包囊生活史。沙门菌为有鞭毛的概括形态，不代表所有血清型。大肠杆菌省略菌株差异较大的鞭毛和菌毛。共读文字保留这些观察限制。

专题内标明 AI 重建、配色示意与不按比例，另保留代码绘制的结构示意供共读对照。源 PNG 接受后移除，不反复重压接受的 WebP。
