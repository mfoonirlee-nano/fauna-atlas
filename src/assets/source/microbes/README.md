# 微生物专题图片

2026-10-09。使用内置 image_gen，每种微生物分别生成一张科学插图，共 10 张。接受的 WebP 位于 `public/images/microbes/<slug>/01-observation.webp`，只在独立微生物专题使用。

## 提示词与记录

- `prompts.json` 保留每张图的实际最终提示词。
- `generation.json` 保留内置工具的原始生成路径；默认生成原图留在 Codex 的 generated_images 目录。
- `accepted-images.json` 绑定运行时路径、实际解码尺寸、SHA-256、字节数及观察重点。

## 检查

生成 PNG 和最终 WebP 均用联络表逐张检查。酵母源图与三种单细胞真核生物源图另作原始分辨率检查，三种真核生物的 WebP 也作原始分辨率检查。主要观察结构可见，没有文字、水印、表情或虚构尺度标尺。贾第鞭毛虫保留两个核和四对鞭毛；草履虫保留短纤毛；眼虫保留叶绿体、眼点及一根伸出的长鞭毛。

通过仓库 convert:webp 流程转换，质量 82；转换前后尺寸一致，最终 WebP 可解码。每张均为 1536×1024，总计 713,422 字节。专题使用完整图片 contain 显示，不接入动物封面轮播或动物分类。

`test:microbes`（5 项）、`test:images`（1 项）与 `test:dist-subpath`（4 项，包含类型检查、生产构建和 JavaScript 预算）通过。新增检查覆盖每种选题唯一保留图片、实际解码尺寸、SHA-256、独立目录、懒加载和 AI 图片替代文字。未启动浏览器，图像检查与 DOM 测试不验证完整页面的浏览器排版。

## 局限

这些是 AI 科学重建，不是真实显微照片，也不证明精确的物种或菌株身份。配色、纹理、透明度、胞内细节及模糊背景属于说明性重建；不按比例，不能据此推断真实尺寸、生态环境或致病性。

贾第鞭毛虫为滋养体，未展示包囊生活史。沙门菌为有鞭毛的概括形态，不代表所有血清型。大肠杆菌省略菌株差异较大的鞭毛和菌毛。共读文字保留这些观察限制。

专题内标明 AI 重建、配色示意与不按比例，另保留代码绘制的结构示意供共读对照。源 PNG 接受后移除，不反复重压接受的 WebP。
