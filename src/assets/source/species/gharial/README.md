# Gharial image set

These six original project images were generated with Codex's built-in image generation tool for the complete Fauna Atlas gharial profile. They share a restrained natural-history editorial direction and keep *Gavialis gangeticus* distinct from broad-snouted crocodilians through the extremely long, narrow jaws, fine near-uniform teeth, low aquatic body and laterally compressed tail. The adult-male frames show a single terminal ghara; the female and subadult frames deliberately omit it. The set covers a sandbar portrait, a documented acoustic-display hypothesis, a free-flowing river mosaic, lateral fish capture, a hole-nest crèche and evidence-led sandbank restoration without presenting release work as a complete conservation solution.

All six runtime selections were accepted after static review at original resolution. The source PNGs are 1536 × 1024, 8-bit RGB images; the derived WebPs decode at the same dimensions. Each frame contains the requested animal and human counts, coherent heads and bodies, continuous tails, and no text, watermark or invented rescue spectacle. Frame 01 keeps the full male and terminal ghara readable. Frame 02 was reframed after review so its localized bubble cloud and the male's complete tail are both visible. Frame 03 retains the full distant animal against open sand. Frame 04 required one revision: the otherwise usable first pass cropped the tail at the left edge, so the accepted runtime image uses the second, zoomed-out composition with the tail tapering to a visible point. Frame 05 was likewise reframed to retain the female's complete tail while keeping eight countable hatchlings outside her jaws and no intact exposed eggs. Frame 06 keeps all three workers separated from the distant gharial and shows no active nest or animal handling.

Frame 02 has an important evidence boundary. Wild adult males have been recorded producing underwater POP signals, but the underwater jaw clap and compact bubble cloud at the base of the ghara come from preliminary clear-water video observations under managed conditions reported in the 2025 anatomical study. The image is therefore a mechanism illustration, not evidence that a bubble cloud has been frame-by-frame confirmed during every wild POP, nor that it is a fixed wild courtship action or an ordinary exhaled call.
