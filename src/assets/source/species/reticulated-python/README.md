# Reticulated python image set

These six source PNGs were generated with Codex's built-in image generation tool as original project imagery for the `Malayopython reticulatus` profile. They are representative editorial reconstructions, not records of named snakes, nests, predation events, plantations, waterways or field surveys.

- Generated: 2026-08-21
- Source format: 1536 × 1024, 8-bit sRGB PNG without alpha
- Runtime format: 1536 × 1024, 8-bit sRGB WebP without alpha
- Runtime conversion: `cwebp -q 82 -m 6 -mt`
- Product credit: `Fauna Atlas · AI 生成原创图像`

The image set follows the evidence boundaries in [`docs/research/reticulated-python-profile.md`](../../../../../docs/research/reticulated-python-profile.md). Every snake uses a natural wild-type phenotype rather than an artificial pet-trade morph. The body is relatively slender for a giant constrictor and carries linked black-edged diamonds instead of the separated saddle blotches typical of a Burmese python. Frame 04 shows ecological proximity, not an observed predation event. Frame 05 shows guarding by coiling but does not claim that reticulated pythons use shivering thermogenesis. Frame 06 represents the difficulty of finding a cryptic snake and does not document a real population count, survey site or encounter.
