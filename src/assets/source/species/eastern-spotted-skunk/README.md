## 事实与图像限制

采用 MDD 拆分后的 Spilogale putorius，排除 S. interrupta；保留 todo 中文名斑灵猫，别名东部斑臭鼬。MDD 列 IUCN 易危，但评估年份及评估与拆分范围的对应尚未独立核实，不把旧广义分布和数量直接套用。

全部图像为 AI 生成科学情景重建。毛色、姿势和花纹用于观察，不作为实拍、精确比例或微细物种鉴定证据。局部图按观察点取景，不同图片不表示同一个体的连续动作。遮挡处不用于数脚趾或爪。
