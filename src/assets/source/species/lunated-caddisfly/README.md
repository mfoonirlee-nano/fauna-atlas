## 视觉记录与限制

源封面和保留 WebP 封面按原分辨率查看；源图库和运行图库分别检查六图联系表。九种视口的静态图片栏模拟检查完整主体与面板边缘分离。源图检查、几何计算与模拟视觉检查分别记录；按项目规则未启动浏览器，模拟不验证浏览器字体或文字、按钮的完整页面排版和实际内容驱动高度。

先找幼虫小筒上的叶片与沙粒，再看伸出的头和脚。对照成虫长触角与屋顶状翅膀；半月斑及幼虫细节为近似重建，不能当作种级鉴定依据。 图片中的翅脉、鳃、滤网和生殖结构可能存在生成误差，不支持种级鉴定或结构精确计数。验收后移除工作区临时 PNG，保留六张 WebP、最终提示词、哈希和验收记录。
