## 限制与压缩

图片为 AI 生成科学情景重建，不代表实拍、同一个体的连续行为或物种间等比例比较。近景与取食场景可裁去无关部位；脚趾可能受草或枝条遮挡，不用遮挡图逐一数趾。静态安全区图用于检查身体边界与页面区域的间距，不代替浏览器截图。图库实际景别可能比提示更宽，以最终图及配文为准。

使用 npm run convert:webp 首次转换，检查解码、尺寸和哈希。不重复压缩运行 WebP；验收后清理临时 PNG。
