## 事实与图像限制

接受名采用 MDD 的 Pteropus medius。旧生态资料使用 Pteropus giganteus；仅引用其印度狐蝠行为，不沿用旧 LC 等级。MDD 当前列 NT，独立评估日期和全球趋势未核实。 图像为生成式情景重建，不作为实拍、精确比例或微细结构鉴定证据。图库近景允许有意截取局部。
