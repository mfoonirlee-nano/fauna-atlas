# 巨大恐爪龙图片集

2026-10-20 使用内置 image_gen 制作。保留一张封面与五张观察图在 `public/images/species/deinonychus-antirrhopus/`。最终提示词、修订与采用键见 [prompts.json](./prompts.json)，资料与分类采用见[第八批研究记录](../../../../../docs/research/todo-extinct-eighth-five-2026-10-20.md)。

巨大恐爪龙有强壮后腿和较长前肢，第二趾爪弯曲而大，长而较僵直的尾巴帮助平衡。图中羽被依据近缘类群比较复原。Ostrom 的骨骼研究帮助人们认识这种活动能力较强的恐龙。恐爪龙本种尚无可确认完整羽被的直接化石证据；图中羽毛借鉴近缘类群，颜色与花纹仍属推测。 图集统一为 AI 科学复原示意；头颈软组织、颜色、羽色、花纹、姿态和植物布景含推测。外观模型不对应实际馆藏或化石，双视角比较不表示真实相遇或雌雄差异。头部观察图采用局部构图。不同年代和地区的物种没有放在同一自然场景。
