## 复原限制

毛色为科学复原选择；未把生成图描述为历史照片，也未加入缺乏证据的育幼或捕食动作。所有骨骼比较候选均未保留；04 图使用外观模型示意，避免将生成的骨骼细节当成标本证据。03 图首版误混其他物种，已整张重做。图集不提供真实比例尺、骨骼计数或精确颜色证据。
