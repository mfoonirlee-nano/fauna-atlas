初稿检查边界约为 (606, 169, 1513, 866)，主体约 907×697 源像素；吻部或附肢进入左侧保留区，未接受。通过内置图像编辑调整位置与占幅，未修改页面 CSS；最终主体尺寸及各图片栏占幅见下表。 初稿背部过高，编辑时一并修正为较低的扁平身体。
