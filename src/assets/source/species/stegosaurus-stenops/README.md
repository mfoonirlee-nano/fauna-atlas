# 装甲剑龙图片集

2026-10-20 使用内置 image_gen 制作，未使用 CLI/API 回退。保留一张封面与五张观察图在 `public/images/species/stegosaurus-stenops/`。最终提示词、修订提示词和采用键见 [prompts.json](./prompts.json)，来源与分类差异见[第七批研究记录](../../../../../docs/research/todo-extinct-seventh-five-2026-10-20.md)。

装甲剑龙的头小，前腿短、后腿长，背上竖着两列交错的骨板。抬起的尾巴末段有两对长刺，合计四根。 伦敦自然历史博物馆的 Sophie 标本属于 Stegosaurus stenops。研究者扫描骨骼与头骨来研究姿势和取食；背板用途仍有多种假说。 图集统一为 AI 生成科学复原示意；色彩、软组织、姿态和植物布景含推测。外观模型不是实际馆藏或化石骨架，双视角不表示两只动物相遇或雌雄差异。头部图采用局部观察构图，不承担封面的全身展示功能。
