沿着颈部看，两列长棘从椎骨向上伸出。它的颈比许多蜥脚类相对短。长棘外包什么软组织，需要结合骨表与内部结构研究。

2022 年研究者检查长棘的骨组织，提出棘间存在软组织连接与皮帆的解释。画面采用皮肤连接的复原方案；皮帆的精确轮廓、颜色和用途仍包含推测。 所有画面均为 AI 科学复原示意，颜色、皮肤、羽毛等软组织及布景含推测。不用生成图推断精确趾数、骨骼尺寸、甲片排列或已确认行为；画面不对应真实馆藏或骨架。
