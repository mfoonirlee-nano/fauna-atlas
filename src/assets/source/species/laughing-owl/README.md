# 笑鸮图片集

2026-10-20 使用内置 image_gen 制作。每种保留一张封面与五张观察图，目录为 `public/images/species/laughing-owl/`。所有最终提示词及修订见 [prompts.json](./prompts.json)，资料见[第五批研究记录](../../../../../docs/research/todo-extinct-fifth-five-2026-10-20.md)。未使用 CLI/API 回退。
