# 雷龙图片集

2026-10-20 使用内置 image_gen 制作。保留一张封面与五张观察图在 `public/images/species/brontosaurus-excelsus/`。最终提示词、修订与采用键见 [prompts.json](./prompts.json)，资料与分类采用见[第八批研究记录](../../../../../docs/research/todo-extinct-eighth-five-2026-10-20.md)。

雷龙颈长，躯干厚重，四条柱状腿支撑身体，长尾末端逐渐变细。它的前腿比后腿短，行走时尾巴抬离地面。研究者通过颈椎、背椎和肩部骨骼等差异区分雷龙与迷惑龙。头部与软组织复原仍有借鉴近缘种的部分，图中的颜色和姿势不属于化石直接记录。 图集统一为 AI 科学复原示意；头颈软组织、颜色、羽色、花纹、姿态和植物布景含推测。外观模型不对应实际馆藏或化石，双视角比较不表示真实相遇或雌雄差异。头部观察图采用局部构图。不同年代和地区的物种没有放在同一自然场景。
