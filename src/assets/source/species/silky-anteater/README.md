## 事实与图像限制

采用 MDD 拆分后的 Cyclopes didactylus；旧文献的中美洲分布不用于本档案。近似种不能只凭生成图鉴定；图片不提供测量尺度。保护等级采用 MDD 所列 IUCN 全球等级，独立评估年份未核实。

全部图片为 AI 生成科学情景重建，不是实拍。毛色、姿势和环境细节不作为近似种鉴定或比例测量证据。局部图按观察点取景，不同图不表示同一个体的连续动作，遮挡处不用于数趾或爪。
