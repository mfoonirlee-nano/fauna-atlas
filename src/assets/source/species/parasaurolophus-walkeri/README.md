# 沃克氏副栉龙图片集

先找宽阔吻部，再沿头顶看到向后伸出的长管状头冠。冠内通道与鼻腔相连，末端没有通向外界的开口，因此不能当作水下呼吸管。 皇家安大略博物馆的模式骨架保存了头冠和大部分身体。通道形状支持共鸣发声的解释，但没有保存真实叫声；其他副栉龙物种的头冠、产地和年代不能直接套到本种。

AI 科学复原示意；颜色、软组织、植物与姿态含推测。副栉龙的带底座画面为构想的外观模型，不对应真实馆藏。头颈观察允许局部构图，其他画面检查完整尾端。精细趾数与甲片排列不从生成图推断。
