# 埃及棘龙图片集

2026-10-21 使用内置 image_gen 制作，一张封面与五张观察图。资料见[第九批研究记录](../../../../../docs/research/todo-extinct-ninth-five-2026-10-21.md)，生成与修订提示词见[prompts.json](./prompts.json)。

先找背上高高的帆，再沿身体找到尾端。背帆内有延长的椎骨棘突，尾部骨骼也支持较深的轮廓；皮肤颜色、帆的花纹和完整软组织形状仍含推测。 研究者结合埃及旧标本记录、摩洛哥骨骼与尾部化石复原身体。原始埃及标本在第二次世界大战中毁损，后来的复原依靠不同标本的比较，未发现一具保存所有部位的完整骨架。

图集为 AI 科学复原示意；鳞色、花纹、软组织、姿态与植物布景含推测。涂装外观模型不对应实际馆藏或化石。头颈观察图允许局部构图，其他画面保留完整尾端。不同年代、地区的动物没有放进同一自然场景。精细趾数与爪形不从生成图片推断。
