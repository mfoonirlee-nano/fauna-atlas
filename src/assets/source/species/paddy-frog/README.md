## 资料与图像局限

GBIF 和 AMNH 的 ASW 接受 Fejervarya multistriata，归入叉舌蛙科、陆蛙属。中国旧文献的 Fejervarya limnocharis 或泽蛙记录可能混有其他近缘种，包括川村陆蛙，不能只按旧名整批合并。

IUCN 发布于 GBIF 的全球受威胁物种名录列为 LC；本次未核实独立评估日期，保留年份空缺，全球等级不代表各地区都常见。IUCN 的 2023-1 类别变化表确认由 DD 调为 LC；发布批次不等于已核实独立评估日期，这一变化也不能直接理解为种群恢复。
