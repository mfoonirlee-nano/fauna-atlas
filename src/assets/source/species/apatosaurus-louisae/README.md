# 路氏迷惑龙图片集

2026-10-20 使用内置 image_gen 制作。保留一张封面与五张观察图在 `public/images/species/apatosaurus-louisae/`。最终提示词、修订与采用键见 [prompts.json](./prompts.json)，资料与分类采用见[第八批研究记录](../../../../../docs/research/todo-extinct-eighth-five-2026-10-20.md)。

路氏迷惑龙躯干宽厚，颈部粗壮，头却小而低长。四肢像柱子，前肢略短，长尾抬起，末端细长。卡内基博物馆的路氏迷惑龙展架曾使用过错误头骨，后经研究换成较低长、近梁龙式的头骨。研究者会随新证据修订复原，完整展架并不意味着每块骨头都无争议。 图集统一为 AI 科学复原示意；头颈软组织、颜色、羽色、花纹、姿态和植物布景含推测。外观模型不对应实际馆藏或化石，双视角比较不表示真实相遇或雌雄差异。头部观察图采用局部构图。不同年代和地区的物种没有放在同一自然场景。
