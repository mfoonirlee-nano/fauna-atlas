# Komodo dragon image set

These six original project images were generated with Codex's built-in image generation tool for the complete Fauna Atlas Komodo dragon profile. They share a restrained natural-history editorial direction and keep adults distinct from crocodiles, fantasy dragons and other monitor lizards through their heavy low-slung body, broad tapered head, strong limbs, rough clay-brown scales and long muscular tail. The juvenile frame deliberately uses the smaller, more slender, patterned tree-dwelling life stage. The set avoids captivity, tourist staging, graphic predation, exposed eggs, text and watermarks.
