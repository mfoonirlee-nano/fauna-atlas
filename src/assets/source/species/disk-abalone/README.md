## 视觉检查与限制

源封面及最终 WebP 按原分辨率检查；源图库和运行图库分别检查六图联系表。九个规定视口的静态图片栏模拟逐种检查，完整主体与图片栏边缘分离。壳孔数及边缘附属结构为近似重建，不作为鉴定依据；图库将空壳和活体分开标注。

放大与内部结构、空壳、幼体及成体分别在图注中标明，非实测比例，不作为鉴定或精确测量证据。保留每种六张 WebP、提示词、哈希与验收记录；验收后删除工作区临时 PNG。

按项目规则未启动浏览器。静态几何与图片栏模拟不验证浏览器字体、完整页面排版或实际内容驱动高度。
