泥鳅用鳃在水中呼吸，也能吞入空气，利用后肠辅助气体交换。2024 年研究用组织切片及影像分析讨论消化与呼吸的分区。水面姿态图只呈现外观；共读不安排离水或缺氧实验。 图片中的细须、鳍条、硬鳞纹理与斑点可能有生成误差，不支持鉴定或精确计数；图像尺度非实测，静图不能证明呼吸、移动或摄食过程。验收后移除工作区临时 PNG，保留六张 WebP、提示词、哈希与验收记录。
