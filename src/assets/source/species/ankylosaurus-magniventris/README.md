# 巨型甲龙图片集

2026-10-22 使用内置 image_gen 制作，一张封面与五张观察图。资料见[第十批研究记录](../../../../../docs/research/todo-extinct-tenth-five-2026-10-22.md)，最终提示词见[prompts.json](./prompts.json)。

从低矮宽阔的身体看向骨甲，再顺着尾巴找到末端骨锤。甲片长在皮肤内，尾锤没有剑龙式长刺；全身甲片的精确排列仍含复原解释。 不同标本分别保存头骨、骨甲和部分尾锤。研究者在 2017 年重评这些骨骼并讨论甲片位置与身体比例；复原需比较近缘种，不能把完整画面说成一具完整出土骨架。

AI 科学复原示意；颜色、软组织、植物与姿态含推测。前侧全身图采用环境中的身体复原，不将它称为真实馆藏或模型照片。头颈观察允许局部构图，其他画面检查完整尾端。精细趾数与甲片排列不从生成图推断。
