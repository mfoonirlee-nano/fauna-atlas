完整主体边界为 (768, 299, 1390, 607)，包含头部、全部可见鱼鳍与尾尖。主体占 622×308 运行图像素，水平中心为 70.25%。左侧 40% 保留环境背景，完整身体在右侧且外缘有真实背景。focalPoint 为 (0.7, 0.5)，只控制焦点，不代替像素边界。
