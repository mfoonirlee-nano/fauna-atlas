# 图特河包头龙图片集

2026-10-22 使用内置 image_gen 制作一张封面与五张观察图。资料见[第十一批研究记录](../../../../../docs/research/todo-extinct-eleventh-five-2026-10-22.md)。最终提示词见[prompts.json](./prompts.json)，存在修订时保留[修订记录](./revisions.json)。

先沿背部寻找一块块骨甲，再看尾端膨大的骨锤。骨甲属于皮肤内形成的骨骼；复原画里的肤色和甲片间的皮肤由画者推测。

研究者比较头骨、颈部甲环和尾部骨骼，辨认图特河包头龙。2013 年的重评把过去混在这个名字下的部分标本分回其他属，旧图鉴中的分布和外形因此需要逐项核对。 所有画面均为 AI 科学复原示意，颜色、皮肤、羽毛等软组织及布景含推测。不用生成图推断精确趾数、骨骼尺寸、甲片排列或已确认行为；画面不对应真实馆藏或骨架。
