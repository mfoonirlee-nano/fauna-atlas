2026-10-20 使用内置 image_gen 制作。保留一张封面与五张观察图在 `public/images/species/velociraptor-mongoliensis/`。最终提示词、修订与采用键见 [prompts.json](./prompts.json)，资料与分类采用见[第八批研究记录](../../../../../docs/research/todo-extinct-eighth-five-2026-10-20.md)。

蒙古伶盗龙头部低长，前肢带羽毛，长尾伸在身后。每只后脚第二趾有弯曲大爪，休息和行走时可将这根爪抬离地面。2007 年研究报告了前臂骨上的羽茎附着突起，支持蒙古伶盗龙具有羽毛。化石没有给出本图所画的完整羽色、纹路和每片羽毛的位置。 图集统一为 AI 科学复原示意；头颈软组织、颜色、羽色、花纹、姿态和植物布景含推测。外观模型不对应实际馆藏或化石，双视角比较不表示真实相遇或雌雄差异。头部观察图采用局部构图。不同年代和地区的物种没有放在同一自然场景。
