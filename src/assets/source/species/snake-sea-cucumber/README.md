## 事实与图像限制

DORIS 与 Naturalis 支持无足目锚参科、分布、体纹及羽状口触手；中文名见海洋保育署。本轮未核实全球评估，NE 不代表无危；不采用照片比例推算体长。 图像为生成式情景重建，不作为实拍、精确比例或微细结构鉴定证据。图库近景允许有意截取局部。
