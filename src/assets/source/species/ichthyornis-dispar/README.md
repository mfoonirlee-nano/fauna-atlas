# 异齿鱼鸟图片集

2026-10-22 使用内置 image_gen 逐张制作一张封面与五张观察图。提示词见[prompts.json](./prompts.json)，修订见[revisions.json](./revisions.json)，完整生成过程见[generation-history.json](./generation-history.json)，资料见[十种灭绝动物研究记录](../../../../../docs/research/todo-extinct-fourteenth-ten-2026-10-22.md)。

全部为 AI 科学复原示意。2018 年研究结合新发现的三维头骨材料和耶鲁模式标本，用 CT 重建颅骨。研究者在图中区分真实保存的骨片与缺失部分。AI 图只概括外形，不能替代这些模型或作为牙齿数目与脑部结构的证据。 体色、软组织、姿态与古环境含推测；画面不对应真实化石或馆藏，不用于计数牙尖、指趾或测量骨骼。
