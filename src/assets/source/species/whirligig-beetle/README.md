## 事实与图像限制

豉甲也可泛指豉甲科，本档案仅指 Gyrinus natator。它与 G. substriatus 等近似种的区别不能靠生成图确认。英国区域记录不代表全球状态；本轮未核实全球 IUCN 等级，NE 不代表无危。 图像为 AI 生成科学情景重建，不作为实拍、连续动作、物种微细鉴定或精确比例证据。叶片、种子等仅提示周围环境与大致大小；局部近景允许有意截取身体。

两张图库重做以去除误导性的浅色边纹。复眼与足部图仅用于认识一般结构，不作为近似种鉴别依据。
