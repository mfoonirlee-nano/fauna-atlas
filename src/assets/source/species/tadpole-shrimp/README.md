## 事实与图像限制

采用 Triops cancriformis，不与海水中的鲎或丰年虾混同。Buglife 列全球未评估；英国区域受威胁信息不替代全球等级。不沿用“同一物种两亿年不变”的说法。 图像为 AI 生成科学情景重建，不作为实拍、连续动作、物种微细鉴定或精确比例证据。叶片、种子等仅提示周围环境与大致大小；局部近景允许有意截取身体。

封面经过构图编辑以保留完整尾丝。干塘图仅表示休眠卵所在环境，不画出放大的卵或干地成体。
