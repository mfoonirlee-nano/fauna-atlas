# 芬氏鸭图片集

2026-10-20 使用内置 image_gen 制作，一张封面和五张观察图保留在 `public/images/species/finschs-duck/`。逐张最终提示词与修订见 [prompts.json](./prompts.json)，来源与内容限定见[第六批研究记录](../../../../../docs/research/todo-extinct-sixth-five-2026-10-20.md)。未使用 CLI/API 回退。

芬氏鸭身体结实，腿粗，喙短而厚，翅膀缩小。少量保存的羽毛多呈银灰色，有细密波纹；完整羽色仍不清楚。 洞穴中的大量遗骨可供比较身体比例。少量羽毛只能约束部分配色，不能确定整只鸟的花纹和雌雄差别。 六张图片均为 AI 生成科学复原示意；羽色、姿态、光线和环境中的植物含推测。外观模型不对应实际馆藏，双视角图供比较同种成年鸟的观察方向，不表达雌雄差异或真实共处事件。异鹩统一采用雌鸟外观，秋沙鸭统一采用雄鸟外观；其余种不凭推测羽色区分性别。
