These six original project images were generated with Codex's built-in image generation tool on 2026-08-28 for the complete Fauna Atlas Emperor Dragonfly profile. The set spans the species' adult identification, pond patrol, oviposition, aerial foraging, aquatic larval life and the empty exuvia left after emergence.

## Shared morphology and evidence boundary

Adult frames keep the Emperor Dragonfly's apple-green thorax, yellow leading wing veins, huge meeting compound eyes and four transparent wings. Mature male frames use a sky-blue abdomen with a dark mid-dorsal line. The oviposition frame uses a representative green female and does not imply that every female has the same colour. The set avoids the Lesser Emperor pattern of a brown thorax with only a blue abdominal saddle.

The aquatic frame shows a streamlined hawker larva with paired wing pads and internal rectal gills. It has no three external leaf-shaped tail gills. The emergence frame shows an empty exuvia, not a living larva or an adult trapped in its old skin.

## Runtime conversion

The six source PNGs were compressed in place with the repository's TinyPNG workflow, then converted with the documented runtime settings:

```bash
npm run compress -- src/assets/source/species/emperor-dragonfly/*.png
npm run convert:webp -- src/assets/source/species/emperor-dragonfly/*-source.png
```

The converter uses `cwebp -q 82 -m 6 -mt` and removes `-source` from each runtime filename.
