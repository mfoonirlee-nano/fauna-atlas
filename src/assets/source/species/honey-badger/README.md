## 目视检查与限制

源封面和运行封面按原始分辨率检查；观察图逐张检查源图，并用运行图联系表复核。以运行封面制作六视口的静态安全区叠加图，复核完整主体、文字区与面板的间距，不启动浏览器。独立图片不表示同一个体的连续动作；自然遮挡的爪趾不用于数数。
