## Taxonomic correction passes

The first versions of frames 01, 02, 04 and 05 inherited the phrase `pointed rostrum`, which conflicted with the rounded-blunt rostral-fin endpoint used in the *B. belcheri* versus *B. japonicum* identification study. Those four source images received imagegen edits before their final compression and WebP conversion.

Each correction targeted only the anterior end: make the rostral-fin endpoint short, gently rounded and blunt; keep the single ventral oral hood and oral-cirri fringe immediately behind it; preserve the narrower pointed tail, notochord, myomeres, median fin fold, pose, lighting and scene. The edits did not add eyes, jaws, scales, paired fins, a second cirri crown, text or another animal.
