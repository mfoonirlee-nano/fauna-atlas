## 完整主体边界

保留 WebP 完整主体边界为 (700, 190, 1455, 834)，包含躯干、全尾及黏液滤食房的全部外缘。主体占 755×644 运行图像素，水平中心为 70.15%。focalPoint 为 (0.7, 0.5)，不代替像素边界。左侧 40% 留作环境背景，主体与源图边缘之间有真实背景。动物身体本身的检查边界约为 (890, 442, 1438, 616)，约 548×174 px；几何适配用包含滤食房的整体边界。黏液房不计入物种体长，图片不按实测比例。

初稿检查边界约为 (520, 90, 1485, 910)，占 965×820 源像素，附肢或滤食房进入左侧保留区，未接受。通过内置图像编辑调整构图，最终尺寸见上文。

## 视觉记录与限制

源封面和保留 WebP 封面按原分辨率查看；源图库和运行图库分别检查六图联系表。九种视口的静态图片栏模拟检查完整主体与面板边缘分离。源图检查、几何计算与模拟视觉检查分别记录；按项目规则未启动浏览器，模拟不验证浏览器字体或文字、按钮的完整页面排版和实际内容驱动高度。

先找透明房子里的躯干，再沿着蓝色边缘找完整的尾巴。房子是黏液结构，不能算作身体；蓝边、滤网褶皱和内部结构为 AI 重建，图像不按实测比例。 图片中的翅脉、鳃、滤网和生殖结构可能存在生成误差，不支持种级鉴定或结构精确计数。验收后移除工作区临时 PNG，保留六张 WebP、最终提示词、哈希和验收记录。
