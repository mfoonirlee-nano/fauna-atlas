## 事实与图像限制

采用 World Spider Catalog 当前园蛛科 Araneidae，不沿用旧金蛛科 Nephilidae。新加坡地方 LC 不作为全球 IUCN 结论；本轮全球等级未核实，记 NE。 图像为生成式情景重建，不作为实拍、精确比例或微细结构鉴定证据。图库近景允许有意截取局部。
