## 完整主体边界

封面完整边界 (730, 170, 1380, 850)，占 650×680 运行图像素；水平中心 68.68%。边界包括头部、所有可见触角、足、尾须或尾刚毛。focalPoint 为 (0.7, 0.5)，不代替完整主体边界。左侧 40% 为安静背景，主体与源图边缘之间有真实背景。

初稿 1536×1024，可见范围约 (610, 80, 1460, 960)，850×880 源像素；前端吻管过于细长，附肢接近留白区。通过内置编辑修正吻管及完整主体构图，补齐封面与背面观察图的第四对行走足。

## 视觉记录与限制

源封面与最终 WebP 按原分辨率查看。源图库与运行图库分别查看六图联系表，九个规定视口分别查看静态图片栏模拟。源图视觉检查、几何计算和运行图模拟检查分别记录。

图片属于 AI 重建，放大、生命阶段和结构示意在图库图注中标明；非实测比例。细小刚毛、刺列、足、触角和感觉器的外观可能有生成误差，不用于鉴定或精确计数。静图不能证明运动过程。

按项目规则未启动浏览器。静态几何与图片栏模拟不验证浏览器字体、文字与按钮排版或实际内容驱动高度。验收后移除工作区临时 PNG，保留六张 WebP、提示词、哈希和验收记录。
