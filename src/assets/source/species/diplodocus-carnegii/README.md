# 卡内基梁龙图片集

2026-10-20 使用内置 image_gen 制作，未使用 CLI/API 回退。保留一张封面与五张观察图在 `public/images/species/diplodocus-carnegii/`。最终提示词、修订提示词和采用键见 [prompts.json](./prompts.json)，来源与分类差异见[第七批研究记录](../../../../../docs/research/todo-extinct-seventh-five-2026-10-20.md)。

卡内基梁龙的长颈、较低的躯干和细长鞭状尾连成修长轮廓。四肢支撑身体，髋部较高，尾巴抬离地面，头部很小。 卡内基博物馆的原始化石与广泛复制的 Dippy 骨架常见于展览。展架可能组合多个个体及补配骨件，复制件不等于每块都来自同一完整个体。 图集统一为 AI 生成科学复原示意；色彩、软组织、姿态和植物布景含推测。外观模型不是实际馆藏或化石骨架，双视角不表示两只动物相遇或雌雄差异。头部图采用局部观察构图，不承担封面的全身展示功能。
