# Eurasian otter image set

These six original project images were generated with Codex's built-in image generation tool for the complete Fauna Atlas Eurasian otter profile. They share a restrained natural-history editorial direction and consistently depict *Lutra lutra*: a long, low mustelid with small rounded ears, a pale throat, webbed feet, and a thick tail that tapers gradually from the pelvis.

No external image was supplied to the model or stored in the repository. The prompts explicitly exclude sea-otter back-floating, Asian small-clawed otter proportions, giant-otter throat markings, beaver or mink anatomy, zoo settings, anthropomorphic behavior, text, logos, and watermarks.

- Editable sources: `*-source.png`
- Runtime assets: `public/images/species/eurasian-otter/*.webp`
- Dimensions: 1536 × 1024
- Runtime conversion: `cwebp -q 82 -m 6 -mt`
- Credit shown in the product: `Fauna Atlas · AI 生成原创图像`

Both were regenerated with targeted anatomy and route-continuity constraints; only the corrected finals are stored here.
