# 异鹩图片集

2026-10-20 使用内置 image_gen 制作，一张封面和五张观察图保留在 `public/images/species/lyalls-wren/`。逐张最终提示词与修订见 [prompts.json](./prompts.json)，来源与内容限定见[第六批研究记录](../../../../../docs/research/todo-extinct-sixth-five-2026-10-20.md)。未使用 CLI/API 回退。

异鹩体型小，橄榄褐色的羽毛间有细纹，眼旁有窄窄的黄眉纹。它的翅膀很短，脚却粗壮，脚趾也大。 研究者用保存的标本核对羽色和脚形；南北两岛出土的遗骨说明，它过去的分布比最后存活的小岛广。 六张图片均为 AI 生成科学复原示意；羽色、姿态、光线和环境中的植物含推测。外观模型不对应实际馆藏，双视角图供比较同种成年鸟的观察方向，不表达雌雄差异或真实共处事件。异鹩统一采用雌鸟外观，秋沙鸭统一采用雄鸟外观；其余种不凭推测羽色区分性别。
