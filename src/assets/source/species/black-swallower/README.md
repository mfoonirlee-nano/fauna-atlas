初稿检查边界约为 (525, 248, 1516, 620)，主体约 991×372 源像素；吻部或附肢进入左侧保留区，未接受。通过内置图像编辑调整位置与占幅，未修改页面 CSS；最终主体尺寸及各图片栏占幅见下表。 初稿第一背鳍过高，编辑时一并修正背鳍与臀鳍轮廓。
