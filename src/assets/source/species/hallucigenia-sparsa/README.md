# 稀有怪诞虫图片集

2026-10-22 使用内置 image_gen 制作一张封面与五张观察图。最终提示词与修订指令见[prompts.json](./prompts.json)，实际尺寸及哈希见[image-acceptance.json](./image-acceptance.json)，资料见[本批研究记录](../../../../../docs/research/todo-extinct-final-2026-10-22.md)。

图片为 AI 科学复原示意。早期研究曾把背刺当作行走的足，把软足当作背部结构。2015 年重述确认头部与口咽细节，也说明压扁化石会隐藏重要结构，研究者会随新证据修改复原。 本目录沿用 GBIF 的有爪动物门归属表示其化石近缘位置，不把它解释为现生有爪动物的冠群成员。 颜色、软组织、动作和布景含推测；生成图不用来鉴别标本、计数结构或测量尺寸。菊石图片只呈现壳体，不指定缺乏证据的腕数与软体外形。
