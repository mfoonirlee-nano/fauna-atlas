多鳍鱼属于辐鳍鱼纲。2014 年研究包含塞内加尔多鳍鱼，记录头部喷水孔参与空气吸入、空气进入肺的过程。鼻端短管与喷水孔不同；水面重建图不证明气流方向。 图片中的细须、鳍条、硬鳞纹理与斑点可能有生成误差，不支持鉴定或精确计数；图像尺度非实测，静图不能证明呼吸、移动或摄食过程。验收后移除工作区临时 PNG，保留六张 WebP、提示词、哈希与验收记录。
