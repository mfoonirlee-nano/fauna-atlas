## 事实与图像限制

爬行动物数据库支持接受名、有鳞目和鬣蜥科。数据库和 ADW 保留部分旧广义分布或近似种资料，因此只写爪哇、巴厘等范围，不照抄印度或新加坡记录，不采用旧文献滑翔距离与繁殖数值。滑翔由肋骨支撑皮膜，非扑翼飞行。 独立评估年份未核实，不以来源访问日期代替。图库经过逐张观察；图像仍为生成式重建，不用于微细结构鉴定。近景允许有意截取局部。修订中纠正了部分封面的左侧侵入，以及极乐鸟尾羽和羽色、母麝牛角基、骆驼脚垫、管虫退缩场景。
