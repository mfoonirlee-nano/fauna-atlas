# 巨型腕龙图片集

2026-10-20 使用内置 image_gen 制作，未使用 CLI/API 回退。保留一张封面与五张观察图在 `public/images/species/brachiosaurus-altithorax/`。最终提示词、修订提示词和采用键见 [prompts.json](./prompts.json)，来源与分类差异见[第七批研究记录](../../../../../docs/research/todo-extinct-seventh-five-2026-10-20.md)。

巨型腕龙前肢长于后肢，肩部高，背部向后倾斜。长颈从厚重躯干前端升起，头部相对于身体很小，四肢像柱子。 本种化石并不完整。全身复原常参考非洲近缘的长颈巨龙 Giraffatitan，不能把近缘种的完整骨架说成本种完整实物；头部和软组织尤其保留推测。 图集统一为 AI 生成科学复原示意；色彩、软组织、姿态和植物布景含推测。外观模型不是实际馆藏或化石骨架，双视角不表示两只动物相遇或雌雄差异。头部图采用局部观察构图，不承担封面的全身展示功能。
