# Polar bear image set

These six source PNGs were generated with Codex's built-in image generation tool as original project imagery for the `Ursus maritimus` profile. They are editorial reconstructions rather than records of named animals, sites, surveys or events.

- Source format: 1536 × 1024, 8-bit sRGB PNG without alpha
- Runtime format: 1536 × 1024, 8-bit sRGB WebP without alpha
- Runtime conversion: `cwebp -q 82 -m 6 -mt`
- Product credit: `Fauna Atlas · AI 生成原创图像`

The image set follows the scientific and editorial boundaries documented in [`docs/research/polar-bear-profile.md`](../../../../../docs/research/polar-bear-profile.md). Frame 01 is morphology-guided artwork, but the image alone cannot establish sex, age, length or mass. Frame 02 illustrates still-hunting behavior only: the opening does not prove a seal was present or that a hunt succeeded. Frame 03 is a generalized habitat mosaic, not a real locality or sea-ice trend graphic. Frame 04 does not establish swim distance, duration, destination or cause. Frame 05 is an evidence-guided maternal scene, not a verifiable family, date or den record. Frame 06 illustrates passive image monitoring; one frame cannot identify an individual, estimate abundance or establish a population trend.
