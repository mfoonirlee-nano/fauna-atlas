# Chinese mountain cat image set

These six original project images were generated with Codex's built-in image generation tool for the complete Fauna Atlas Chinese mountain cat profile. They share a restrained natural-history editorial direction and avoid desert dunes, zoo fixtures, people, text, anthropomorphic staging, Pallas's cat anatomy, and domestic-tabby body markings.

The IUCN/SSC Cat Specialist Group's published species photograph was used only as a morphology reference for the stocky proportions, grizzled coat, small ear tufts, pale eyes, and bushy terminally ringed tail. It is not stored in the repository and no accepted image copies its pose, background, text, signature, or watermark. The approved cover was then used as the project-local appearance and style reference for frames 02–06.
