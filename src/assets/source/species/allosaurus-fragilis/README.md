# 脆弱异特龙图片集

2026-10-20 使用内置 image_gen 制作。保留一张封面与五张观察图在 `public/images/species/allosaurus-fragilis/`。最终提示词、修订与采用键见 [prompts.json](./prompts.json)，资料与分类采用见[第八批研究记录](../../../../../docs/research/todo-extinct-eighth-five-2026-10-20.md)。

脆弱异特龙用强壮后腿行走，头骨两眼上方有低矮骨质突起。它每只手有三根带爪手指，长尾帮助平衡身体。研究者比较头骨、牙齿、四肢和相关咬痕来研究异特龙。多个个体同层埋藏不能单独证明合作围猎；骨质突起的用途也仍有讨论。 图集统一为 AI 科学复原示意；头颈软组织、颜色、羽色、花纹、姿态和植物布景含推测。外观模型不对应实际馆藏或化石，双视角比较不表示真实相遇或雌雄差异。头部观察图采用局部构图。不同年代和地区的物种没有放在同一自然场景。
