霸王龙的头骨大而深，后腿强壮，前肢却短，每只手有两根主要手指。粗长尾巴帮助平衡身体，行走时尾端抬离地面。 研究者比较头骨、牙齿、咬痕和部分皮肤印痕。印痕提供局部鳞片证据，不能据此确定全身颜色，也不能排除未保存部位的未知外观。 图集统一为 AI 生成科学复原示意；色彩、软组织、姿态和植物布景含推测。外观模型不是实际馆藏或化石骨架，双视角不表示两只动物相遇或雌雄差异。头部图采用局部观察构图，不承担封面的全身展示功能。
