# 奥克兰秋沙鸭图片集

2026-10-20 使用内置 image_gen 制作，一张封面和五张观察图保留在 `public/images/species/auckland-island-merganser/`。逐张最终提示词与修订见 [prompts.json](./prompts.json)，来源与内容限定见[第六批研究记录](../../../../../docs/research/todo-extinct-sixth-five-2026-10-20.md)。未使用 CLI/API 回退。

奥克兰秋沙鸭头颈深褐，背部深灰，雄鸟头后有长羽冠。细长的喙边缘有锯齿状结构，脚呈橙色。 标本的胃内容物记录了鱼骨和无脊椎动物遗存；骨骼稳定同位素研究支持它兼用海水与淡水取食环境。 六张图片均为 AI 生成科学复原示意；羽色、姿态、光线和环境中的植物含推测。外观模型不对应实际馆藏，双视角图供比较同种成年鸟的观察方向，不表达雌雄差异或真实共处事件。异鹩统一采用雌鸟外观，秋沙鸭统一采用雄鸟外观；其余种不凭推测羽色区分性别。
