# 里奥格兰德恐鳄图片集

2026-10-22 使用内置 image_gen 逐张制作一张封面与五张观察图。提示词见[prompts.json](./prompts.json)，修订见[revisions.json](./revisions.json)，资料见[十种灭绝动物研究记录](../../../../../docs/research/todo-extinct-next-ten-2026-10-22.md)。

全部为 AI 科学复原示意。恐鳄的头骨比例不同于现生短吻鳄。2025 年研究用头宽及系统发育方法重新估计体长，结果低于一些旧估计；因此这里不写一个没有误差的最大体长，也不按影视尺寸画体型比较。 皮肤、毛被颜色、软组织、姿态与古环境含推测；画面不对应真实化石或馆藏，不用于计数牙尖、指趾或测量骨骼。
