# 三角龙图片集

2026-10-20 使用内置 image_gen 制作，未使用 CLI/API 回退。保留一张封面与五张观察图在 `public/images/species/triceratops-horridus/`。最终提示词、修订提示词和采用键见 [prompts.json](./prompts.json)，来源与分类差异见[第七批研究记录](../../../../../docs/research/todo-extinct-seventh-five-2026-10-20.md)。

三角龙头后有宽大的骨质颈盾，两根长眉角伸向前方，鼻子上还有一根较短的角。它用四肢支撑厚重身体，嘴前端呈喙状。 研究者用头骨、角芯、牙齿和皮肤印痕认识三角龙。不同头骨的大小和形状会随个体与生长阶段变化，不能看到一点差别就另立物种。 图集统一为 AI 生成科学复原示意；色彩、软组织、姿态和植物布景含推测。外观模型不是实际馆藏或化石骨架，双视角不表示两只动物相遇或雌雄差异。头部图采用局部观察构图，不承担封面的全身展示功能。
