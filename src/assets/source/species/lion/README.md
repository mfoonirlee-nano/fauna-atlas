## Shared morphology and evidence boundary

The adult scenes use a tawny coat, rounded ears, pale underparts, a long tail with a dark terminal tuft, and realistic large-cat proportions. The adult male carries a mane around the head, neck, and shoulders; the lionesses remain maneless. Mane size, coat tone, belly contour, and group composition vary across the species, so the pictures cannot determine subspecies or represent every population.

The resting group cannot establish kinship, pride membership, dominance, or territory size. The hunting frame shows spacing and shared orientation; one still cannot prove coordination, prey choice, attack timing, success, or food sharing. The nursery frame cannot identify mothers, prove nursing or allonursing, count a litter, or estimate cub survival. The camera-trap frame demonstrates a non-contact method; one generated record cannot establish occupancy, abundance, density, identity, or trend, which require repeated sampling, individual identification, and an appropriate model.

## Compression and runtime conversion

The repository compression script sent the six source PNGs through TinyPNG, then converted them with the repository's `cwebp` settings:

    npm run compress -- src/assets/source/species/lion/*.png
    npm run convert:webp -- src/assets/source/species/lion/*-source.png
