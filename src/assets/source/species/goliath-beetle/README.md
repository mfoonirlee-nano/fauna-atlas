## 图像限定

AI 生成科学情景重建。图片放大展示，无实测比例；叶片和树枝不是比例尺。表面纹理、体节、刺与细丝有艺术简化，不能用于物种鉴定、结构计数或测量。雌雄、不同阶段与颜色分别展示，不表达连续实拍或同一个体的变化。

栗褐色鞘翅上的浅色边纹范围有个体差异，图集不代表同一个体。体长参照采用成人在纸上画 10 cm 线段，未把树枝当实测比例尺。
