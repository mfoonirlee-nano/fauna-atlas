# 南岛厚嘴鹤图片集

2026-10-20 使用内置 image_gen 制作，一张封面和五张观察图保留在 `public/images/species/south-island-adzebill/`。逐张最终提示词与修订见 [prompts.json](./prompts.json)，来源与内容限定见[第六批研究记录](../../../../../docs/research/todo-extinct-sixth-five-2026-10-20.md)。未使用 CLI/API 回退。

南岛厚嘴鹤头骨厚重，喙长、粗壮而向下弯，末端尖。颈部粗，腿和脚趾短而有力，翅骨缩小到外观难以看见。 骨胶原的氮稳定同位素组成支持较高营养级，结合头骨等证据，研究者认为它捕食动物；每一种具体猎物仍属推测。 六张图片均为 AI 生成科学复原示意；羽色、姿态、光线和环境中的植物含推测。外观模型不对应实际馆藏，双视角图供比较同种成年鸟的观察方向，不表达雌雄差异或真实共处事件。异鹩统一采用雌鸟外观，秋沙鸭统一采用雄鸟外观；其余种不凭推测羽色区分性别。
