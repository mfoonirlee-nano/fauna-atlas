运行封面完整边界 (880, 165, 1380, 865) 包含所有可见触角、足、翅和尾端附肢，占 500×700 运行图像素，水平中心 73.57%。focalPoint 为 (0.7, 0.5)，不代替完整边界。左侧 40% 留作背景，主体与源图边缘之间有真实背景。

初稿源图为 1536×1024，视觉估计的可见主体范围约 (750, 0, 1355, 960)，占 605×960 源像素。初稿附肢靠近源图边缘或进入左侧保留区；通过内置图像编辑缩小并右移完整主体后接受。保留图为外观近似重建，不支持显微鉴定或结构精确计数。

## 视觉记录与限制

源封面和最终 WebP 按原分辨率检查；源图库与运行图库分别查看六图联系表。九种视口的静态图片栏模拟检查完整主体和边缘分离。源图视觉检查、几何验算与模拟视觉检查分别完成。

按项目规则未启动浏览器。静态模拟不验证浏览器字体、文字、按钮及实际内容驱动高度。图库标注雌雄、若虫和成虫；内部结构图为简化示意，非实测尺度。足的重叠、翅脉、触角及微小结构可能存在生成误差，不能用作物种鉴定或精确计数。验收后移除工作区临时 PNG，保留六张 WebP 与提示词、哈希及验收记录。
