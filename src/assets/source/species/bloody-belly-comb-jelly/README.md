## 视觉检查与限制

输入检查：源图联系表覆盖六个场景，封面按原始分辨率查看。最终 WebP 检查：封面按原始分辨率复核，六张运行时图通过联系表检查。视觉模拟：查看当前规则下九档图片栏，背景用同一封面的模糊暗化副本，主体与面板边缘保留背景，文案及按钮使用现有独立布局区域。

按仓库要求未启动浏览器。静态几何与图片栏模拟不能验证浏览器字体、内容驱动的实际高度或完整页面排版。采用模拟观察灯表现红色与梳板衍射，非深海自然照明；细小纤毛为重建，不用于计数。
