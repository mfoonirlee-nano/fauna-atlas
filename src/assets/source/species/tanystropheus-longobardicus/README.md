# 长颈龙图片集

2026-10-22 使用内置 image_gen 制作一张封面与五张观察图。提示词见[prompts.json](./prompts.json)，初稿与修订见[revisions.json](./revisions.json)。资料见[第十三批研究记录](../../../../../docs/research/todo-extinct-thirteenth-five-2026-10-22.md)。

2020 年研究发现，小型标本的骨组织显示它们已经成熟，于是将大型标本另立为 T. hydroides。本档案保留小型种 T. longobardicus，不把大型种头骨或巨大尺寸混入；皮肤、颜色与水中姿态含推测。

画面均为 AI 科学复原示意；姿态、皮肤、颜色、鳍膜与海底布景含推测。不将画面称为真实化石或馆藏，不从生成图测量骨骼或推断固定行为。长颈龙图中的长颈和脚趾、沧龙类尾鳍均按比较复原理解，不能用图计数颈椎、趾数或牙尖。
