# Western gorilla image set

These six original project images were generated with Codex's built-in image generation tool for the complete Fauna Atlas Western gorilla profile. They share a restrained natural-history editorial direction and depict *Gorilla gorilla* without borrowing the high-altitude setting or long shaggy coat associated with the eastern mountain gorilla.

No external wildlife photograph was supplied to the model or stored in the repository. The prompts below are the production records for the accepted images; no generated draft required a follow-up edit.

- Editable sources: `*-source.png`
- Runtime assets: `public/images/species/western-gorilla/*.webp`
- Dimensions: 1536 × 1024
- Runtime conversion: `cwebp -q 82 -m 6 -mt`
- Credit shown in the product: `Fauna Atlas · AI 生成原创图像`

The set is explanatory natural-history imagery, not a record of a named site, individual, group, survey or monitoring outcome. Frames 01–06 use the western lowland subspecies as a visible representative of the species; the profile text separately covers the Cross River subspecies and its more restricted upland range. Frame 03 is a generic bai-like wet clearing and does not expose a real locality. Frame 04 shows an ordinary loose vegetation platform rather than a woven structure. Frame 06 depicts a passive camera trap only: it does not imply that one image identifies population size, and it contains no bait, handling, collaring or precise location data.
