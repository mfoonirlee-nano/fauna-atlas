# 儿童讲解解说图

2026-11-11，用户授权为首批五种动物生成解说图片。每种一张，分别解释前掌和牙齿、脚背孵卵、四阶段成长、八腕和吸盘、象牙和臼齿。

运行图片位于 `public/images/learning/<slug>/`，各目录的 `acceptance.json` 保存提示词、参考来源、生成文件名、返修记录、验收范围以及 WebP 尺寸、字节和哈希。生成 PNG 与最终 WebP 均已目视核对；临时转换副本已删除，工具原件留在工作区 `generated_images`，不提交 Git。

熊猫后臼齿已返修，避免原图近似人类方形四尖牙。帝王蝶幼虫足部初稿含糊，最终改为背面视角，足部自然遮挡；该图只用于四阶段成长，不用于数足。章鱼按八腕逐一核对，吸盘放大图不算额外的腕。帝企鹅卵位于体外脚背，腹部皮肤褶覆盖。猛犸象牙齿图为不按比例的科学复原，不能当作真实标本照片。

这些图单独登记于 `learning.illustrations`，章节通过 `sections[].images` 引用。封面和原五张图集保持原路径；待修复图片不得借此重新公开。图片图注及替代文本标明教学范围，署名保留 AI 生成或科学复原性质。

本次由助手对照参考资料并目视验收，尚未独立专家复核或亲子试读。哈希、压缩、尺寸和页面测试只验证技术属性。
