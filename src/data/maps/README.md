# World land base map

`land.geojson` is Natural Earth's 1:110m land geometry, downloaded from:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson

Natural Earth provides public domain map data: https://www.naturalearthdata.com/about/terms-of-use/
Retrieved 2026-10-14. The map depicts land without political boundaries. Species points use existing
`distribution.center` values, which represent a map focus rather than occurrence records or full ranges.
